## 1. Что изменилось после вашего разбора 09.11

Главное: появились **8 настоящих сканов студии** (кронштейн, крышка, деталь «гольф»,
заглушка порога Hyundai, деталь соковыжималки, линза, детали RAV4 и Terrano). Сканы
лежат только у меня во временной папке, в репозиторий не попадают. Эталонных
CAD-моделей к ним нет, поэтому меряю только «модель против скана».

Реальные сканы сразу сломали предпосылку «механическая призматическая деталь»:
большинство — изогнутые пластиковые оболочки. Поэтому за сутки добавлены методы для
деталей любой формы. Сейчас программа запускает несколько попыток и берёт лучшую по
сравнению со сканом:

| Попытка | Что строит | Для каких деталей |
|---|---|---|
| 0 | слои по сечениям, точные отверстия, достройка скола | призматические, точёные |
| 0б | черновик из стенок (пластины по парам параллельных сторон) | тонкостенные |
| 0в | тело по поверхности скана (замкнутая сетка → тело) | любая форма, но треугольники |
| 0к | **гладкое тело** из B-сплайн граней + точные плоскости | любая форма, редактируемые грани |
| 0ж | уточнение размеров граней по точкам скана | после 0 |
| 0е/0и | Point2STEP (внешняя модель, GPL) и объединение | если установлен |
| 0г/0д/0з | StepCAD, CADENA (локальные ИИ-модели) | выключены по умолчанию |

## 3. Как устроено гладкое тело (чтобы было что критиковать)

1. Скан чистится и упрощается до замкнутой поверхности ~20 тыс. треугольников.
2. Она грубо упрощается (800 → 1500 → 4000 треугольников, пока точность не дойдёт до
   98% в пределах 0,2 мм).
3. Каждый треугольник делится на 3 четырёхугольника. В каждом сетка 5–9 × 5–9 точек
   кладётся на поверхность с той же стороны стенки.
4. По точкам интерполируется B-сплайн грань. Общие границы соседей совпадают точка в
   точку, поэтому грани сшиваются без щелей.
5. Смешанная модель: лоскуты плоских участков кладутся точно на плоскость участка, на
   стыке двух плоскостей — на линию их пересечения. Потом связная группа сливается в
   одну плоскую грань. Если слияние портит тело, берётся тело без слияния.

## 4. Что я сам считаю слабым

1. **Граней тысячи.** Это уровень «автоповерхности» Geomagic/QuickSurface, а не
   дерево построения инженера. Открыть в SolidWorks можно, поправить скругление —
   нет. Свести кривую оболочку к десяткам граней надёжно не успею: нужна разметка
   детали на области и раскладка лоскутов по ней, это несколько дней.
2. **Цилиндры не выделяются.** Отверстия вырезаются точными цилиндрами отдельным
   шагом, но бобышки и кривые стенки-цилиндры остаются сплайнами. Мой поиск
   цилиндров по лоскутам (ось по нормалям, окружность по точкам, рост области) пока
   не срабатывает даже на синтетике.
3. **Нет эталонов студии.** Все 99% — «модель повторяет скан». Повторить скан —
   не то же, что восстановить замысел конструктора, и не то же, что достроить
   сломанное. Для изогнутых оболочек достройки скола нет вообще.
4. **Скорость на ПК Якова.** На его машине крупный скан идёт 15–25 минут. На показе
   живой прогон рискован, нужны заранее готовые отчёты.
5. **Отбор попыток по числам.** «Лучшая» выбирается по совпадению со сканом и
   обязательным проверкам. Тело из треугольников (0в) почти всегда выигрывает по
   совпадению, поэтому гладкому телу дан допуск в 1 процентный пункт. Это ручное
   правило.
6. **Метрика зависит от шума.** На шумном скане (Hyundai, шум ~0,7 мм) допуск
   сравнения сам поднимается до ~2 мм. 100% «в допуске» там значит меньше, чем
   на синтетике.
