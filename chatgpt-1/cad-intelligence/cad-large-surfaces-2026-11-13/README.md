# Задача 47. Крупные гладкие грани

Модуль восстанавливает односвязную свободную зону с прямоугольной проекцией на четыре заданные боковые плоскости. Он строит замкнутое тело с плоским дном. Оси и границы определяются из плоскостей, направление высоты — из нормалей скана. Локальная подгонка использует кубический тензорный B-сплайн с весами по плотности, робастным перевзвешиванием и штрафом за вторую разность полюсов. Параметрические клетки образуют отдельные четырёхугольные грани на одной поверхности. Поэтому обе стороны внутреннего стыка используют ту же кривую и ту же производную поверхности. Наружные изолинии лежат точно на опорных плоскостях и входят в контуры боковых граней как пространственные рёбра. [API построения граней OCCT](https://dev.opencascade.org/doc/refman/html/class_b_rep_builder_a_p_i___make_face.html)

Подход применим к локальным зонам без нависающих частей. Непрямоугольный контур, цилиндрические соседи, отверстия внутри зоны и автоматическое построение карт на произвольной детали остаются открытыми. В штатный сборщик модуль пока не подключён.

## Проверка

21 вход при σ 0, 0,1 и 0,2 мм. Это листы R50–R300, седло, купол R100, участок тора и повёрнутый синтетический аналог боковины. Ещё шесть прогонов тора и аналога боковины сделаны на неравномерной сетке с другим seed. Все 27 STEP валидны. В каждой свободной зоне восемь сплайн-граней, ноль треугольных граней, не меньше 144 мм² на одну грань. По 11 пробам на каждом из десяти внутренних стыков максимальный угол меньше 0,000002°, минимальная доля триангулированной площади каждой грани — 99,76%. Покрытие в обе стороны при 0,3 мм составило 100% относительно чистого эталона. Полный синтетический прогон одного входа занял до 0,88 с. Проверка студийной кнопки ещё нужна. [Результаты](results.json)

В первом прогоне штраф 0,08 сгладил полезную кривизну и снизил покрытие, на торе до 77,5% в худшем направлении. Штраф 0,001 выбран по этому стенду. Для приёмки на кнопке нужен её исходный скан, границы зоны и базовый STEP с той же системой координат. В репозитории и проверенных локальных папках этих файлов нет. Прототип для изолированного теста записывает результат только при выполнении ограничений по углу, плотности граней, триангуляции и покрытию относительно переданного STEP.

## Запуск

Из корня общего репозитория в окружении CAD-демо.

```powershell
$c = 'chatgpt-1/cad-intelligence'
$task = "$c/cad-large-surfaces-2026-11-13"
$env:PYTHONPATH = "$task;claude/cad-demo;$c/cad-detail-preservation-2026-11-13"
python "$task/benchmark47.py" --work "$env:TEMP/sever47"
python "$task/benchmark47.py" --irregular --seed 4709 --case torus --case button_side_control --work "$env:TEMP/sever47-irregular"
python "$task/fit_zone.py" scan.stl supports.json baseline.step candidate.step
```

`supports.json` содержит `zone_faces` (индексы треугольников исходного файла), `support_normals` (четыре наружные нормали), `support_origins` (четыре точки на тех же плоскостях) и `bottom_point` (точка на дне).
