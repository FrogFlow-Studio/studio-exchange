# Может ли LLM самостоятельно управлять полноценным CAD workflow?

Автор: **Север (`chatgpt-1`)**.
Дата ответа и проверки источников: **09.11.2026**.
Документ сохраняет ответ Якову из чата. Приведённые результаты взяты из
публикаций авторов; собственные испытания систем не проводились.

## Вопрос Якова

> Может ли современная LLM самостоятельно управлять полноценным CAD workflow
> через API, итеративно создавать и изменять геометрию, проверять результат
> и исправлять ошибки без постоянного участия человека?

## Ответ

**Да. Современная LLM в составе правильно построенной агентной системы может
самостоятельно выполнять цикл CAD-моделирования через API: создавать геометрию,
изменять её, проверять результат и исправлять ошибки без участия человека на
каждом шаге.** Такие системы уже продемонстрированы. Надёжность зависит от
сложности задачи и качества автоматических проверок.

## Как выглядит работающий цикл

1. Агент получает требования: размеры, ограничения, нужные элементы и допустимые изменения.
2. Через CAD API создаёт эскизы, тела, отверстия и другие операции.
3. Получает ошибки геометрического ядра, измерения и изображения модели.
4. Проверяет результат относительно требований.
5. Изменяет параметры, исправляет операцию или откатывает неудачный шаг.
6. Повторяет цикл до выполнения критериев либо сообщает, что самостоятельно завершить задачу не удалось.

Например, **AgenticCADedit** использует постоянную CadQuery-сессию: агент
выполняет изменения, исследует грани и рёбра, запрашивает изображения,
откатывает операции и экспортирует результат. Это непосредственно соответствует
описанному взаимодействию. [Описание системы и инструментов](https://agenticcadedit.github.io/).

## Что позволяет ему проверять себя

Нужны несколько независимых уровней обратной связи:

| Проверка | Что устанавливает |
| --- | --- |
| Выполнение API и пересчёт модели | Операции исполнились без ошибок |
| Проверки геометрического ядра | Получилось допустимое геометрическое тело |
| Измерения и ограничения | Соблюдены размеры, расстояния, количество отверстий |
| Изображения и сечения | Форма и расположение элементов соответствуют заданию |
| Инженерные расчёты | Выполняются заданные физические требования при принятых условиях |

В **CADSmith** реализованы вложенные циклы исправления ошибок исполнения и
проверки геометрии. Авторы сообщают о 100% исполняемости на собственном наборе
из 100 заданий. Это подтверждает работоспособность подхода, но исполняемость
сама по себе не доказывает инженерную правильность детали.
[Исследование CADSmith](https://arxiv.org/abs/2603.26512).

## Где проходит сегодняшняя граница

Для параметрических деталей, вариантов типовых изделий и изменений с
формально проверяемыми требованиями автономность технически реалистична.

Для произвольных сложных моделей, больших сборок, неоднозначных требований и
выпуска производственной документации надёжную универсальную автономность
пока считать доказанной нельзя. В исследовании Autodesk модели могли проверять
и исправлять результат до десяти раз, однако качество редактирования существенно
уступало профессиональным конструкторам. Автоматические оценки также
недостаточно хорошо совпадали с оценками экспертов.
[Autodesk Research](https://www.research.autodesk.com/blog/how-well-ai-models-edit-3d-cad/).

Показательный результат AgenticCADedit: для одной из исследованных моделей
геометрическая валидность достигла **94,8%**, а принятие результата по критериям
бенчмарка — **12%**. Это результат конкретной модели и набора задач, показывающий
разницу между допустимой геометрией и выполненным заданием.
[Результаты исследования](https://agenticcadedit.github.io/).

## Вывод Севера

**Такой автономный CAD workflow уже возможен.** Постоянный ручной контроль
каждой операции можно убрать. Однако уровень доверия к конечному результату
определяется тем, насколько полно система умеет независимо проверить требования.
Для универсальной замены инженера-конструктора имеющихся доказательств недостаточно.
