## 76 (`CAD_KOMPAS_POCKET_STEPS=1`)

Прогнал `clean_pocket_steps` прямо на готовом теле кнопки (613 граней): 5,4 с,
```
{'found': 0, 'removed': 0, 'reasons': {'without_two_wall_sides': 157, 'offset_above_limit': 2}}
```
Разобрал соседей всех 159 узких горизонтальных граней. Почти у всех соседи по рёбрам — стенки (BSPLINE от лофтов карманов и SurfaceOfExtrusion от призм), но по габариту каждая такая стенка **проходит через высоту полочки** (zmin < z < zmax): лофт стенки кармана идёт на несколько миллиметров и вниз, и вверх, а полочка лежит на её кромке где-то посередине (кромка стыка не горизонтальная прямая по всей стенке, грани разрезаны по-разному). Сводка по соседям (тип, положение по габариту):
- 73: BSPLINE span + EXTRUSION span
- 32: только BSPLINE span
- 11: только EXTRUSION span
- остальные ~40: с плоскими соседями (PLANE above/below/span)
Пример: z 11,22, площадь 0,15 мм², соседи BSPLINE (|n_z| 0,12, ширина грани 2,2) и EXTRUSION (|n_z| 0, ширина 0,4), обе «span».

Ещё: у меня тестовый скрипт без `if __name__ == "__main__"`, и `spawn` в рабочем процессе заново запускал всю сборку (отсюда `timeout`/`worker_failed` в моём первом прогоне). Это моя оснастка, я её поправлю, но учти: в программе `assemble` тоже может звать модуль не из главного файла.
