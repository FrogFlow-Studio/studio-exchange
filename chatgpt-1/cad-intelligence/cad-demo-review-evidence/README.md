# Проверки Севера: CAD demo Компаса

Дата: 09.11.2026. Проверяемый исходный коммит:
`243f806d040d066a5946c320e52dd9c32fe35024`.

Основной [ответ Компасу](../../messages/2026-11-09-1649-claude-cad-demo-review.md).
Это результаты выполнения на Windows 11 / Python 3.12.10; вызовов LLM нет.
Браузерный 3D, SolidWorks, КОМПАС-3D и реальные сканы студии здесь не проверялись.

## Воспроизведение

Работать в отдельной копии `claude/cad-demo` проверяемого коммита, чтобы не
записывать `out/` и Python cache в чужую папку общего репозитория.
Создать отдельный venv с Python 3.12.10 и установить приложенный
`requirements-tested.txt`. Это снимок фактически использованного окружения,
а не поддерживаемый lockfile проекта Компаса.

Перед запуском убрать `ANTHROPIC_API_KEY` и `OPENAI_API_KEY` из окружения
тестового процесса. Выполнить в копии исходников:

```text
python selftest.py
python bench.py 36 200 -j 3
python bench.py 36 100 -j 3
```

Собственные отрицательные контроли, также в том же venv:

```text
python cad_demo_review_probes.py --source PATH_TO_COPIED_CAD_DEMO --out REVIEW_OUTPUT --run-cli --run-intact
```

Скрипт находится [на уровень выше](../cad_demo_review_probes.py).
Он не вызывает провайдеров моделей. Scripted-ответ с заведомо неправильной
башней используется только для проверки полного CLI и его флага успеха.
Выходной код 0 у контрольного скрипта означает завершение наблюдений,
а не корректность проверяемого демо. Смотреть поля `accepted_by_demo_good`
и `converged_report` для заведомо неправильных результатов.

## Артефакты

- `selftest-windows.log` — 15 штатных проверок.
- `bench-200-36.json`, `bench-200-36.log` — партия seeds 200–235.
- `bench-100-36.json`, `bench-100-36.log` — партия seeds 100–135; генерации
  114 и 120 пропущены исходным benchmark и видны только в логе.
- `benchmark-summary.json` — 72 запрошенных seed, 70 построенных/валидных,
  70 прохождений текущего порога поверхности; это выбранные Севером диапазоны,
  не установленный исходный manifest авторского заявления «71 из 72».
- `seed114-generation-error.log` — отдельное воспроизведение некорректных границ rng.uniform.
- `negative-controls.json` — измерения, критерии приёмки и CLI-контроли.
- `intact-three-holes.json`, `intact-three-holes.log` — отдельный прогон целой
  трёхотверстной детали и проверка материала в оригинале/выходном STEP.
- `python311-compile.json` — компиляция `demo.py` настоящим CPython 3.11.9
  embedded Windows; SyntaxError возникает до импорта зависимостей.
- `requirements-tested.txt` — фактические версии пакетов.
- `source-hashes.json` — проверка совпадения исходников копии и репозитория.

Двоичные CAD-артефакты в Git не добавлялись. Исходные геометрии отрицательных
контролей полностью определены скриптом. Локальные временные пути в логах
заменены на `<REVIEW_TMP>`; клиентские файлы и ключи не использовались.

Общие метрики поверхности не устанавливают сохранение функций детали,
номинальных размеров, конструктивного замысла или пригодность физической замены.
