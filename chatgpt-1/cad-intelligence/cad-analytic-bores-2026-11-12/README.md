# Задача 17. Точные отверстия в 0к без выреза из готового тела

[Патч](analytic_bores.patch) добавляет опытный путь `CAD_ANALYTIC_BORES=1` в `geo_worker.py`. Он подходит для деталей с постоянным наружным профилем по направлению отверстий и с двумя параллельными торцами. По сечениям исходного скана определяются центры и цилиндрические участки. Основной диаметр берётся из штатного поиска отверстий. Увеличенный диаметр цековки и положение уступа проверяются по данным скана. Наружная стенка, торцы с круглыми контурами, цилиндрические стенки и кольцевые уступы сшиваются в замкнутое тело. В этом пути булев вырез по готовому телу не вызывается. [Open CASCADE Sewing](https://dev.opencascade.org/doc/refman/html/class_b_rep_builder_a_p_i___sewing.html)

Кандидат должен быть одним валидным замкнутым телом с положительным объёмом и допусками рёбер в пределах порога сшивки. Покрытие скана в обоих направлениях при 0,3 мм должно быть не ниже покрытия исходного 0к. Используются фиксированные 4 000 проб скана и отдельные 4 000 проб на каждой модели. Если кандидат набирает 100% в обоих направлениях, сравнение с исходным телом можно пропустить. Отклонённый или неподдерживаемый случай возвращается к штатному пути `surface.cut_holes`. Флаг выключен по умолчанию.

## Измерения

На исходной синтетике новый путь принят на двух пластинах. Получено **8 из 8** эталонных цилиндрических участков. Это четыре сквозных отверстия и два отверстия с цековками. На остальных проверенных деталях кандидаты отклонены. В сумме на всех восьми деталях стенда новый путь дал 8 из 25 эталонных участков.

| --- | ---: | ---: | ---: | ---: | ---: | --- |

В колонках сравниваются цилиндрические участки внутренних стенок. У цековки нижний и верхний диаметры считаются отдельно. Пары проверяются по стенду задачи 12 с радиусом ±0,1 мм, осью ±2°, смещением оси до 0,25 мм и границами по глубине до 0,5 мм. Число принятых булевых операций само по себе не подтверждает полную стенку. Например, часть отверстия может быть вырезана только на участке глубины.

На обеих принятых деталях после перечитывания STEP покрытие исходного скана и эталона составило 100% в обоих направлениях при 0,3 мм. На исходной сетке у пластины с отверстиями штатный путь дал 71,38% / 72,88% к скану, у пластины с цековками — 87,75% / 91,10%. Участок работы с отверстиями занял 41,1 → 2,3 с и 23,9 → 1,3 с соответственно. На корпусе с рёбрами попытка нового пути добавила около 0,7 с, затем выполнился прежний путь.

По замечанию Компаса дополнительно пересобрал две пластины из STEP в Gmsh с целевым ребром 1 мм. После добавления шума 0,05 мм медиана ребра составила 0,99 и 1,00 мм. На такой сетке штатное покрытие скана уже 100,00% / 100,00% и 99,98% / 100,00%. Новый путь дал 100% / 100% на обеих деталях и сохранил **8/8** полных цилиндрических участков. Максимальные ошибки радиуса и оси составили 0,013 мм и 0,14°. Участок работы с отверстиями занял **39,8 → 1,4 с** на первой пластине и **11,2 → 0,9 с** на второй. На равномерном входе подтверждены точные стенки и экономия времени. Большая разница покрытия на исходной сетке связана с её чувствительностью к очистке. [Руководство Gmsh](https://gmsh.info/doc/texinfo/gmsh.html)

Время измерено на одном этапе `_build` при `CAD_REGIONS=1`, без каскада и последующих скруглений. Стоимость общего поиска отверстий исключена из обоих режимов. Синтетические тела первой ступени взяты из прогона задачи 15 на том же коде движка. Время разных фаз измерено на одном ПК при перекрывающихся прогонах, значения ориентировочные. [Числа, ошибки параметров и откаты](results.json).

## Где метод пока не срабатывает

Локальная замена лоскутов на готовом 0к не дала пригодных двух контуров в проверенных случаях. Часть лоскутов пересекала кромку или соединяла разные области. Для корпуса с рёбрами и тестового кронштейна плоскости вокруг отверстий не ограничивают всю деталь, поэтому сборка из одного наружного профиля отклоняется. Округлый паз на одной синтетике штатный детектор посчитал круглым отверстием, а проверка сечений это предложение отклонила. На сферической детали штатный детектор не нашёл отверстие. Студийный кронштейн и его время откатов здесь не измерялись.

## Воспроизведение

База `20afb985f7332fd3a64fce4901fd236ac8b9f1e0`. Используй Python-окружение CAD-демо. В `$artifact` укажи путь к этой папке, в `$runs` — отдельный каталог прогонов. Патч применяется из корня checkout.

```powershell
git apply --check "$artifact/analytic_bores.patch"
git apply "$artifact/analytic_bores.patch"
$env:PYTHONUTF8 = '1'
$env:OPENBLAS_NUM_THREADS = '1'
python "$artifact/benchmark_bores.py" --demo claude/cad-demo --work $runs
```

Для отдельного прогона на равномерной сетке установи `gmsh==4.15.2` в окружение стенда и используй другой каталог результатов.

```powershell
python "$artifact/benchmark_bores.py" --demo claude/cad-demo --work $uniformRuns --uniform --case drilled_plate counterbored_plate --boolean drilled_plate counterbored_plate
```

Можно выбрать детали через `--case`. `--reuse` использует уже подготовленные локальные STEP и замеры. Сравнение со штатными булевыми по умолчанию выполняется для двух пластин и корпуса с рёбрами. Стенд проверяет повторное чтение STEP. Дополнительно проверены две ветки `geo_worker` с подстановкой сохранённых тел одной ступени. На принятой пластине вызов штатных вырезов отсутствовал, на отклонённом корпусе был один вызов запасного пути. `selftest.py` прошёл на Python 3.12, Python 3.10 и 3.11 локально отсутствуют. Платный ИИ не использовался.
