# Задачи 12 и 13. Проверка STEP и полный A/B

## Задача 12. Независимая приёмка геометрии

`geometry_acceptance.py` перечитывает итоговый STEP и исходный STEP-эталон средствами OCC. Стенд проверяет валидность, замкнутость оболочек, число тел и наличие отдельно лежащей геометрии. Смежные грани на одной аналитической поверхности объединяются. Для цилиндров проверяются радиус, направление и поперечное положение оси на высоте эталонного элемента, а также обе границы вдоль оси. Для плоскостей проверяются нормаль, смещение и отклонение точек. Для конусов проверяются ось, полуугол и радиус в опорном сечении. Сферы и торы проверяются по аналитическим параметрам. Цилиндрическое скругление определяется по касательным стыкам с двумя разными поверхностями.

Допуски зафиксированы до запуска. Для радиуса и плоскости это 0,15 мм, для смещения оси 0,25 мм, для угла оси 2°, для угла плоскости и полуугла конуса 1°, для осевых концов 0,5 мм. Для покрытия используется допуск 0,3 мм. Тесселяция 0,03 мм и 0,10 рад, по 4000 случайных проб на направление, seed 19213. Допуски и матрицы выравнивания записаны в JSON. При сопоставлении используется одна пара на элемент. Сначала максимизируется число пар в допуске, затем число правдоподобных пар. Ошибки параметров, пропущенные и лишние элементы считаются отдельно.

Все три модели получены штатным `demo.py --mode geometric` на `f582bec6644a067ea53e7442640f556151002414` с `CAD_REGIONS=0`. Конвейер выбрал маршрут 0ж. Эталон преобразован из координат исходного скана матрицей из `sheet.json`. Все итоговые STEP содержат по одному валидному замкнутому телу.

| --- | ---: | ---: | ---: | ---: | --- |
| Фланец | 11 | 1 | 0 | 0 | 100,0% / 100,0% |
| Втулка с пазом | 8 | 1 | 2 | 8 | 100,0% / 100,0% |
| Тестовый кронштейн | 14 | 3 | 7 | 260 | 98,8% / 98,4% |

- Фланец. Все семь цилиндрических отверстий прошли проверку, а одна плоскость смещена на 0,186 мм при допуске 0,15 мм.
- Втулка. Обе модели совпали в допуске 0,3 мм на всех пробах. Наружные цилиндры R25 и R15 не найдены как точные цилиндрические грани в восстановленном STEP. Там есть поверхность вращения и конус. Одна плоскость отклонена на 1,13° при допуске 1°.
- Тестовый кронштейн. В STEP отсутствуют четыре точные цилиндрические грани скруглений R5. Наружный цилиндр R13 совпал по радиусу и оси, его осевой конец расходится с эталоном на 10,02 мм. Большинство лишних граней — плоские фасеты. Этот счётчик измеряет аналитические грани STEP и может быть большим у фасеточного представления.

Проверка фиксирует аналитические поверхности в том виде, в каком их прочитал OCC. Сплайн или поверхность вращения могут приближать цилиндр с малым отклонением. Это отражается в покрытии, а точная грань считается пропущенной. Оценка опорной области плоскости использует ограничивающие прямоугольники в её координатах. Сложные контуры и назначение детали эта проверка не сертифицирует. Полное внутреннее цилиндрическое отверстие считается по направлению нормали и приблизительному угловому охвату от 330°. Подрезанные отверстия могут остаться частичными внутренними цилиндрами. Максимум отклонения относится к выборке.

Команды выполняются из корня общего репозитория в окружении CAD-демо.

```powershell
$dir = 'chatgpt-1/cad-intelligence/cad-acceptance-2026-11-12'
python "$dir/test_geometry_acceptance.py" -v
python "$dir/geometry_acceptance.py" --model $step --reference $truth --sheet $sheet --out "$env:TEMP/geometry.json" --report "$env:TEMP/geometry.md"
```

Если модель и эталон уже в одной системе координат, опусти `--sheet`. Без `--reference` сохраняются только данные итогового STEP. В [geometry_results.json](geometry_results.json) указаны параметры обеих сторон, ошибки и статус каждого элемента.

## Задача 13. Полный A/B

`benchmark_regions_full.py` запускает геометрический маршрут от чтения скана до итогового STEP. В обоих вариантах одинаковы входы, допуски, интерпретатор и ограничения потоков. Варианты отличаются указанным SHA и флагом `CAD_REGIONS`. Скрипт проверяет чистоту исходников и SHA до и после прогона, сверяет хеши входов, меняет порядок A/B через повтор и создаёт отдельный каталог для каждого процесса. Независимое сравнение с эталоном выполняется после остановки таймера конвейера. Эталон не передаётся в команду построения.

Время до STEP фиксируется при первом обнаружении полностью записанного итогового файла. Полное время включает завершение отчёта программы. RAM — максимум суммарного RSS родителя и его дочерних процессов по пробам каждые 0,2 с. Это приближение, которое может пропустить короткие пики и дважды учитывать разделяемые страницы. Суммы времени параллельных стадий могут превышать полное время. Из программы берутся только существующие замеры. Сегментация и тегирование в текущей версии измеряются совместно, чистый экспорт отдельно не измерен. Ошибки и откаты записываются там, где конвейер публикует счётчики. Отсутствующие замеры остаются пустыми.

Проверочный запуск A приведён в [ab_smoke.md](ab_smoke.md), сырые метрики — в [ab_smoke.json](ab_smoke.json). Он прошёл штатным маршрутом 0ж, где региональная стадия не наблюдалась. В [конфигурации](benchmark_config.json) SHA B оставлен пустым до появления принятой версии этапа Б с интеграцией задачи 11. Студийные входы и STEP-эталоны можно добавить в ту же конфигурацию. Недоступные сканы выводятся отдельными строками. Запуск A/B требует два закреплённых checkout и не стартует с пустым SHA B.

```powershell
git worktree add --detach $checkoutA $shaA
git worktree add --detach $checkoutB $shaB
python "$dir/benchmark_regions_full.py" --config "$dir/benchmark_config.json" --checkout-a $checkoutA --checkout-b $checkoutB --out $newOutputDir
```

В конфигурации по умолчанию три повтора. При отдельной проверке одного запуска A добавь `--smoke-case flange` вместо `--checkout-b`. Файловый кэш ОС сохраняется. Флаг регионов может не использоваться, если конвейер выбрал ранний маршрут. В таблице A/B для каждой детали есть число успешных прогонов B, в которых региональная стадия наблюдалась.
