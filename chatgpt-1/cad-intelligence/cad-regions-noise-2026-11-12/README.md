# Задача 10. Разметка областей на шумном скане

Патч применяется поверх задачи 9. Он проверяет окружение грани по топологии сетки и наблюдаемой смене нормалей. При высоком шуме требуется больше подтверждённой границы. В повторном поиске плоскости растут на сглаженных нормалях, а близкие точки исходного скана уточняют положение и ориентацию. Плоскости, найденные повторным поиском, должны иметь подтверждённую соседнюю поверхность или подходящую противоположную стенку. Подтверждённые плоскости задают дополнительные сечения для поиска цилиндров.

Разметку можно вызвать как `segment(mesh)` или передать исходные точки через `segment(mesh, scan=scan)`. В замерах использован второй вызов. Индексы и площади относятся к очищенной сетке. Поле boundary_support содержит долю периметра предложения вблизи наблюдаемой смены нормалей. Для конуса дополнительным подтверждением может быть plane_boundary_support.

## Воспроизведение

Из корня studio-exchange в окружении CAD-демо. Если код задачи 9 уже применён, начните со второго патча.

```powershell
$task9 = 'chatgpt-1/cad-intelligence/cad-regions-2026-11-12'
$task10 = 'chatgpt-1/cad-intelligence/cad-regions-noise-2026-11-12'
git apply "$task9/regions.patch"
git apply --check "$task10/regions-noise.patch"
git apply "$task10/regions-noise.patch"
$env:OPENBLAS_NUM_THREADS = '1'
python "$task10/benchmark_noise.py" --repo . --out "$env:TEMP/regions-noise.json"
python claude/cad-demo/selftest.py
```

Стенд поднимает исходный код задачи 9 из её патча и сравнивает обе версии на одной очищенной сетке. Используются те же детали, зерно 20261112 и допуски на параметры, что в [стенде задачи 9](../cad-regions-2026-11-12/README.md). Добавлены уровни σ 0,4 и 0,7 мм. Время относится только к разметке. На 0,05 и 0,2 мм и трёх STL сравнение использует сохранённые измерения задачи 9 на тех же сетках. Сборка исходного скана, очистка и сопоставление с эталоном выводятся отдельными этапами. Доля ложной площади включает ошибочные участки внутри частично верных областей и плоские поверхности сколов, которых нет в исходной детали.

## Приёмка

- На крышке и торе максимальная доля ложной площади 1,2% на всех четырёх уровнях. На оболочке ложная площадь плоскостей 1230 → 1908 мм² при 0,05 мм и 1480 → 1839 мм² при 0,2 мм.
- Полнота фланца 80,2% → 86,8%. Строгий допуск прошли 5 из 5 размеченных стенок R4. На втулке с пазом полнота 69,7% → 79,1%.
- На корпусе полнота при σ 0,2 15,7% → 54,8%. Это 70,1% от результата при σ 0,05. Ложная площадь при σ 0,2 выросла с 4,8% до 8,0%, поэтому совместное условие по полноте и ошибкам на корпусе ещё не выполнено.
- По таблице выше видны случаи, где проверка границы отбрасывает правильные области. На конусной втулке при σ 0,2 мм полнота снизилась с 38,2% до 21,0%. При σ 0,7 мм стенд показывает 0–2,2% полноты. Измерения на сканах студии нужны перед подключением в путь автоматической реконструкции.
- Оба патча применены по очереди в чистом worktree. Штатный selftest прошёл 27 из 27 проверок. Студийные сканы и платный ИИ не использовались.
