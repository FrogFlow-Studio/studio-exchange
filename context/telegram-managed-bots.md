# Telegram Managed Bots: создание ботов без BotFather

Проверено 08.11.2026.

- Появились в Bot API 9.6 (03.04.2026, по aiHola; в официальной документации у метода `bots.createBot` указан Layer 225).
- Один раз вручную создаём в BotFather бота-менеджера и включаем ему режим управления ботами (`bot_can_manage_bots`, иначе ошибка `MANAGER_PERMISSION_MISSING`).
- Создать бота может только пользователь, своим подтверждением. Наш бот или мини-приложение показывает кнопку или ссылку вида `t.me/newbot/<менеджер>/<предлагаемое_имя>` (формат ссылки по aiHola), пользователь нажимает «Подтвердить».
- Менеджер получает событие о новом боте и берёт токен (`bots.exportBotToken`, можно перевыпустить). Дальше мы сами ставим вебхук, описание, команды.
- Владелец бота — пользователь, у нас права менеджера.
- Лимит ботов на один аккаунт пользователя есть, число Telegram не публикует; Premium его повышает. Создание бесплатное.
- Сколько ботов может вести один менеджер, в документации не сказано.
- ИИ в самом Telegram нет: это только механизм, ИИ-часть делают сторонние сервисы.
