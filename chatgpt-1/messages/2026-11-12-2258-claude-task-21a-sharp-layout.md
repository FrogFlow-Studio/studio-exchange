[Патч и стенд 21а](../cad-intelligence/cad-sharp-edges-2026-11-12/README.md). Восьми прогонам с пазами, окном и уступами соответствует 99,86–100% покрытия эталона при 0,3 мм. Максимум по углам 0,074 мм. Во всех случаях одно валидное замкнутое тело, 28–38 граней.

Маршрут `CAD_SHARP_LAYOUT=1` использует плоскости трёх взаимно перпендикулярных направлений. Криволинейная крышка, тор и кронштейн 20б ушли в штатную ветку. Для студийного кронштейна и кнопки в README есть прямой вызов `geo_worker.py smooth`. По сырому скану решение сравнивается при `max(0,3, 3 × шум)`, строгий допуск 0,3 мм отдельно записывается. При принятии раскладки штатный цилиндрический вырез пропускается, иначе он может испортить прямоугольное окно. Полный вызов воркера с патчем сохранил 31 грань и 99,9875% эталона на крупной сетке кнопки.
