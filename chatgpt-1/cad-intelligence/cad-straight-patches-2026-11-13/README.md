# Задачи 27–29. Гладкие зоны и проверка прямого тела

## 27. Гладкая грань по границе сетки

`patch_faces.patch(V, F, faces_of_zone, tol)` строит одну пластинчатую B-сплайн-грань средствами OCC. Граничные отрезки задаются как ограничения C0. Начальные внутренние точки распределяются по пятну. При превышении допуска добавляются до четырёх худших проб и поверхность пересчитывается, всего до шести попыток. Для зоны с дыркой внутренний контур задаётся отдельными ограничениями и затем врезается в грань с восстановлением параметрических кривых рёбер.

Проверяются тип и концы каждого исходного прямого отрезка, валидность грани, отклонение всех внутренних вершин от обрезанной грани, ориентация нормали в центре каждого треугольника и отношение площадей в интервале 0,78–1,22. Поле `edge_tolerance_mm` показывает допуск между пространственным ребром и его представлением на поверхности OCC. Этот допуск может быть выше 0,001 мм при неизменной пространственной линии. В стенде соседние грани строятся отдельно и шьются при допуске 0,001 мм.

Для больших зон `split_zones` отделяет компоненты по перепаду нормалей от 50° и делит их до 64 граничных отрезков и 240 треугольников. При откате одного пятна вызывающий код может передать его исходные треугольники в сшивку.

Контрольный стенд содержит R5, седло, купол и купол с отверстием. При шуме 0,1 мм внутренние точки сдвинуты вдоль Z, граница взята после предполагаемого выпрямления. При допуске 0,3 мм для всех восьми сочетаний получены одно валидное тело и ноль свободных рёбер. Максимум времени 1,18 с на 200 треугольниках. В отдельном прогоне с шумом и на границе три из четырёх шумных пятен прошли. Седло с seed 47 откатилось из-за роста площади на 55%, исходные треугольники для него остаются рабочим вариантом. [Результаты сшивки](patch_results.json)

## 28. Случайные CAD-контроли для 0п

`straight_fuzz.py` генерирует ребристую пластину, уголок с отверстиями и скруглениями, основание с бобышками, ступенчатый вал, наклонную деталь и тонкие стенки. Gmsh сглаживает неравномерную сетку с целевым шагом 0,8–2 мм. Шум добавляется по нормалям вершин. Отдельно проверяются толщина и ступень 0,18 мм при допуске 0,3 мм, а также наклон 2,5°. Стенд прогоняет именно ядро `idealize → collapse_degenerate → planar_brep.build` на исходном скане. Достройка сколов и последующее вырезание отверстий в демо в этот тест не входят.

Покрытие считается в обоих направлениях между эталонным CAD и итогом через `compare.compare`, до 1 500 проб на направление, один seed. Допуск `3 × noise` для нулевого шума оставлен пустым. Для каждой эталонной плоскости сохраняются угол и нормальный сдвиг до найденной опоры. Для прямых острых рёбер между плоскостями берутся пять проб и расстояния до ближайших почти параллельных сегментов; большая величина может означать отсутствие подходящего ребра рядом. В JSON есть число проб в допуске 0,3 мм, чтобы отличить этот случай от небольшого смещения. Параметры каждого входа, шум, seed, SHA, времена и исходные метрики записаны в отчёте.

Худшие случаи исходной 0п на `d3110b7`:

| Случай | Измеренный результат | Что проверить в ядре |
| --- | --- | --- |
| `--case shaft --seed 27 --noise 0.2` | Покрытие 98,53% / 97,13% при 0,3 мм и 100% / 99,87% при 0,6 мм. Осталось 2 075 треугольников | Цилиндрические участки всё ещё строятся треугольниками |
| `--case shaft --seed 91 --noise 0.2` | Плоские области занимают 13,19%. У одной крупной плоской опоры ошибка 5,45° и 0,77 мм | Проверить разметку и опоры на торцах вала |
| `--case angle --seed 27 --noise 0.2` | 54 из 60 проб острых рёбер в 0,3 мм при покрытии поверхности 99,67% / 98,93%. Две опорные плоскости не сопоставились | Рёбра между разбитыми плоскостями могут пропасть при высоком покрытии |
| `--case near_parallel --seed 27 --noise 0.05` | Обе стороны ступени сохранились. Рост высоты в сечении между −0,05 и +0,05 мм от линии ребра всего 0,034 мм при номинальном скачке 0,18 мм | Исходное выпрямление превращает резкую ступень в короткий наклон |

На 33 входах обе версии ядра вернули валидные замкнутые тела без свободных рёбер. Максимум исходного времени ядра 5,56 с. При шуме 0,05 мм контроль стенки 0,18 мм показал толщину 0,177–0,187 мм на девяти внутренних лучах. Наклон 2,5° измерен как 2,504°. При seed 91 и шуме 0,2 мм высоты по обе стороны ступени различаются на 0,142 мм, но прямо у ребра рост на отрезке 0,1 мм стал отрицательным (−0,019 мм). Проверки толщины и угла относятся к выбранным сечениям. [Отчёт по всем входам](straight_results.json)

## 29. Связка разметки и выпрямления

`straight_plus.build` добавляет узкие плоскости и касательные цилиндры в копию разметки. Плоская полоска отклоняется, если её эффективная ширина `area / length` не превышает пять оценок шума. Плоскость или скругление отклоняются, когда скан подтверждает соосное цилиндрическое кольцо на его радиусе по семи из двенадцати угловых секторов. Без проверки ширины шумные торцы стенки 0,18 мм увеличивали число треугольников с 235 до 1 858, а у шумной ступени возникали лишние пересечения контрольного луча возле ребра. С проверкой оба шумных контроля повторили исходную геометрию.

| A/B, seed 27 и шум 0,2 мм | Треугольники | Плоская площадь | Балл | Изменение покрытия при 0,3 мм, п. п. |
| --- | ---: | ---: | ---: | ---: |
| Ребристая пластина | 647 → 324 | 87,84% → 93,08% | 81,42 → 87,68 | −0,33 / −0,26 |
| Наклонная деталь | 108 → 24 | 96,61% → 99,13% | 90,04 → 96,36 | 0,00 / −0,07 |
| Уголок | 813 → 733 | 87,13% → 89,37% | 85,25 → 89,00 | −0,34 / −0,73 |
| Вал | 2 075 → 2 018 | 32,38% → 34,16% | 41,60 → 43,12 | +0,07 / −0,26 |

Две ложные оценки скругления на валу отклонены проверкой кольца. На чистой ступени 0,18 мм дополнение вернуло резкий переход. При шуме защитная проверка сохранила исходный пологий переход. На уголке без шума найдены пять полосок скруглений, в них добавлены четыре треугольника. Число треугольных граней итогового тела при этом выросло с 380 до 388, поскольку сборщик всё ещё использует фасеточный маршрут. Из-за потерь покрытия опытную версию стоит сравнивать с исходной по каждому скану перед выбором результата.

Разметка скругления растёт по связным треугольникам в аналитическом секторе между линиями касания, с контролем радиуса и высоты. В отчёте указаны точные концы обеих линий и расстояния от точек разметки до каждой линии на пяти участках. Треугольник, пересечённый линией касания, пока остаётся целым. Дошивка в точную геометрию требует провести линию касания через такие треугольники и дать обеим соседним граням один контур.

В текущем `planar_brep.build` цилиндрические метки превращаются в треугольники. Кроме того, `idealize.regularize_cylinders` может заново оценить радиус независимо от касания. Для подключения точной грани следует сохранить связь с двумя плоскостями, пересчитать касательный цилиндр после выравнивания плоскостей и собрать общие рёбра. Если торцы перпендикулярны оси, `cylindrical_face` даёт две прямые линии касания и две круговые дуги. Прямые должны войти в контуры боковых плоскостей, дуги — в контуры торцов. На косом торце нужно вычислять пересечение цилиндра с его плоскостью и передавать общую кривую обеим граням. При несшивке или ухудшении геометрии остаются исходные треугольники.

`benchmark_cylinder_sew.py` заменяет эталонную цилиндрическую грань R5 своим построением и сшивает её с двумя касательными плоскостями и торцами. Получено валидное тело, ноль свободных рёбер, ошибка объёма менее 0,000001 мм³.

## Запуск

Из корня общего репозитория в окружении CAD-демо с Gmsh 4.15.2.

```powershell
$task = 'chatgpt-1/cad-intelligence/cad-straight-patches-2026-11-13'
$quality = 'chatgpt-1/cad-intelligence/cad-clean-geometry-2026-11-13'
$env:PYTHONPATH = "$(Resolve-Path 'claude/cad-demo');$(Resolve-Path $quality)"
python "$task/benchmark_patches.py" --out "$env:TEMP/patches.json"
python "$task/benchmark_patches.py" --out "$env:TEMP/patches-boundary.json" --seed 47 --boundary-noise
python "$task/straight_fuzz.py" --work "$env:TEMP/straight-seed27" --seed 27 --plus
python "$task/straight_fuzz.py" --work "$env:TEMP/straight-seed27" --seed 27 --case subtol_wall --case near_parallel --case near_slope --noise 0.05 --plus
python "$task/straight_fuzz.py" --work "$env:TEMP/straight-seed91" --seed 91 --noise 0.2 --plus
python "$task/benchmark_cylinder_sew.py"
```
