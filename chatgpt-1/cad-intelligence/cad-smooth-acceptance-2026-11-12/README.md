# Задача 15. Приёмка точных граней первой ступени 0к

Разметка подняла число эталонных плоскостей в допуске с **23/110 до 34/110**, цилиндров — с **0/42 до 2/42**. Оба совпавших цилиндра найдены в корпусе с рёбрами при шуме 0,05 мм. Среди 18 пар, где оба режима вернули валидный B-rep, число лишних аналитических признаков стенда выросло с 51 до 182 для плоскостей и с 0 до 16 для цилиндров. Лишний признак может быть фрагментом верной поверхности, который стенд не сопоставил один к одному. Медианное время первой ступени выросло с 16,7 до 39,5 с по всем 20 парам.

На округлой оболочке оба режима не собрали тело при обоих уровнях шума. При 0,05 мм этап `coarse` с разметкой занял 246,5 с из 267,3 с. При 0,2 мм блок с пазом без разметки прошёл проверку B-rep, но после чтения STEP имел объём −27 117 мм³. Точка (60, 60, 60) мм вне габарита классифицировалась как внутренняя. С разметкой объём +27 129 мм³, та же точка классифицируется как внешняя. Таким образом, положительный объём и валидный замкнутый STEP получены в 17/20 прогонах без разметки и 18/20 с разметкой.

## Методика

Семь деталей задачи 9 и три задачи 11 экспортированы в STEP. Из эталона получена треугольная поверхность целой детали. Добавлен независимый гауссов шум по координатам вершин с σ 0,05 и 0,2 мм. У каждого уровня один и тот же скан для обоих режимов, а у двух уровней одной детали одно поле шума в разном масштабе. Искусственный скол не добавлялся, чтобы измерить влияние разметки при известной исходной геометрии. Для самой плотной сетки запрошено прореживание до 65 000 треугольников до шума. QEM остановился на 172 772 треугольниках, фактическая плотность сохранена в JSON.

Общая предобработка повторяет 0к, `surface.surface_mesh` и `flatten_planes`. Прогоняется один вызов `nurbs._build` с первым набором параметров `(1500, 17, 10, PAIR=True)`, без каскада и без вырезания отверстий после сборки. Варианты чередуются по порядку запуска. Перечитанный STEP проверяется на валидность, замкнутость и одно твёрдое тело. Время — только `_build`, с параллельными группами прогонов на одном ПК. Для оценки времени всего маршрута нужны отдельные прогоны.

Пары граней и ошибки параметров считаются алгоритмом задачи 12. Обрезанные аналитические поверхности измеряются по отдельным граням, покрытие измеряется по сетке тела с абсолютным отклонением 0,03 мм. В каждом направлении по 4 000 проб, порог 0,3 мм. Для эталон → модель координаты проб одинаковы в обоих режимах. Для модель → эталон каждая сетка семплируется отдельно, поэтому небольшую разницу в этом направлении проверяли дополнительным контролем.

## Где теряется покрытие

- **Коническая втулка, σ 0,2 мм.** На цилиндрических лоскутах с разметкой 13 из 54 проб были дальше 0,3 мм от эталона, ближайшая грань эталона у всех 13 — конус. Одна проба на плоскости тоже вышла за допуск и оказалась ближе всего к конусу. Худшая проба на цилиндре у широкого торца — 0,399 мм, координаты (21,43, 0,02, 0,47) мм. При этом обе торцевые плоскости вошли в допуск и общее покрытие модель → эталон почти совпало с контролем на сплайнах, 96,38% против 96,33%. Глобальная метрика скрыла локальную ошибку.
- **Блок с пазом, σ 0,05 мм.** Самое большое снижение модель → эталон, 98,83% → 96,92%. При той же раскладке с разметкой и сохранением сплайнов получилось 97,05%. Все 123 пробы за допуском при разметке лежали на сплайнах. Для этой детали основная потеря сохраняется при отключении замены точными гранями.
- **Ступень со скруглениями, σ 0,05 мм.** Наибольший выигрыш эталон → модель, 65,40% → 98,28%. В обоих STEP по пять плоских граней, а плоскостей в допуске стало 0 вместо 1. Выигрыш по поверхности и результат приёмки точных граней разошлись.
- **Пластина с отверстиями.** До разметки штатная очистка снизила покрытие эталона в 0,3 мм с 100,00% до 65,53% при σ 0,05 мм и с 98,78% до 51,60% при σ 0,2 мм. Это подтверждает отдельный источник потерь в предобработке этой синтетики.

В шести контрольных прогонах исходные теги и раскладка режима с разметкой сохранены, а `_merge_planes` возвращала сшитые сплайны. Ни одна фиксированная проба эталона не пересекла порог 0,3 мм при переходе от этого контроля к точным граням. В обратном направлении пробы взяты на самих моделях, что позволило локализовать ложный цилиндр на конусе. Для задачи 19 эти результаты поддерживают проверку покрытия по локальным областям и отдельную проверку ориентации после чтения STEP. Студийные детали в этот прогон не входили.

## Воспроизведение

База `9d0ea7305d8435038bff2fbff221534d742ac63f`, код CAD-демо совпадает с `3a2dd20`. Запуск в Python-окружении CAD-демо из корня checkout. `$artifact` — каталог этого стенда, `$runs` — новый каталог для расчётов, `$inputAudit` — отдельный каталог для проверки очистки.

```powershell
$env:PYTHONUTF8 = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
python "$artifact/benchmark_smooth.py" --demo claude/cad-demo --work $runs --diagnose
python "$artifact/benchmark_smooth.py" --demo claude/cad-demo --work $runs --audit-controls
python "$artifact/benchmark_smooth.py" --demo claude/cad-demo --work $inputAudit --audit-input --case drilled_plate tapered_bushing
```

Для проверки одного набора можно передать `--case`. JSON сохраняется после каждой завершённой пары. STEP-файлы остаются в каталоге прогонов. `selftest.py` завершился успешно под Python 3.12. Python 3.10 и 3.11 в окружении отсутствовали. Платный ИИ не использовался.
