# Задача 22. Неопределённость сглаженного скана

На сглаженной сетке задача 20а меряет остаточное рассеяние вершин вокруг локальной квадратики. Поверхность после сглаживания может давать почти нулевой остаток. По одному STL нельзя восстановить ни исходный шум сканера, ни стёртую мелкую геометрию, ни систематический сдвиг. Число 0,0000089 мм на Hyundai следует трактовать как остаток аппроксимации сетки. По нему нельзя установить, что именно ограничило значение: округление, предварительное сглаживание или способ построения сетки.

`scan_uncertainty.estimate(mesh)` возвращает исходную оценку 20а в `measured_mm`, её вершинную составляющую в `vertex_sigma_mm` и отдельное рабочее значение `working_mm` для настройки сравнений.

```text
working_mm = max(measured_mm, floor_mm)
floor_mm = max(0,01 × медиана ребра, полудиагональ округления STL, оценка стрелы хорды)
```

- 1% медианного ребра — инженерный резерв при отсутствии метрологии сканера. Он положителен на плоской сетке. Это явно настраиваемая величина политики оценки, её нельзя читать как доказанную точность сканера.
- Для бинарного STL половина шага float32 по каждой оси вычисляется по диапазону координат до выравнивания. Для других файлов этот компонент остаётся неизвестным. [NumPy spacing](https://numpy.org/doc/2.1/reference/generated/numpy.spacing.html)
- Когда остаток вершин ниже резерва, на гладких смежных треугольниках оценивается `κ ≈ угол между нормалями / расстояние между центрами` и локальная стрела `κ h²/8`. Берётся p75, значения ограничены десятой долей медианного ребра. Резкие двугранные углы и вырожденные пары исключаются. Это приближение для гладкой части формы. По измеримому шуму нормалей стрелу не оцениваем.

Если 20а не набрала достаточно окрестностей, `measured_mm` может быть пустым. Рабочая нижняя граница тогда определяется доступной геометрией сетки. Для пустой сетки нет оценки. Поля `limiting_component` и `noise_method` позволяют различить эти случаи.

## Места использования в CAD-демо

Ниже поведение в `875a0f0` при подстановке меньшего `noise_mm`. Для примера число 0,713 → 0,022 мм показывает порядок эффекта, а не результат студийного прогона задачи 22.

| Место | Текущее правило | Эффект меньшего значения |
| --- | --- | --- |
| `demo.py:638,677–695`, `bench.py:230` | Сравнение `max(--tol, 3 × noise)`, штатный минимум 0,3 мм | Допуск 2,14 → 0,30 мм. Процент покрытия может снизиться на той же модели. |
| `geo_worker.py:358–380` | Приёмка 0к `max(0,3, noise)`. В режиме `CAD_FIT_TOL=wide` используется `3 × noise` | Штатный предел 0,713 → 0,30 мм. Более грубая ступень может откатиться, число граней и время могут вырасти. |
| `gates.py:43–62` | Обязательны найденные круглые отверстия с `Ø ≥ 3 × noise` и подтверждением на соседних сечениях | Нижний порог Ø2,139 → Ø0,066 мм. Больше мелких контуров попадут на проверку. Само разрешение отверстия должно подтверждаться сечениями и локальным шагом. |
| `demo.py:1072` | Проверка размеров отверстий в отчёте с `max(0,2, tol/2)` | Допуск 1,07 → 0,20 мм при штатном `--tol`. |
| `scan_analysis.py:183–206,507–511` | Группировка уровней по зазору `max(0,4, 4 × noise)`, предупреждение при `noise > 0,1` | Зазор 2,852 → 0,4 мм. Соседние уровни легче различить, предупреждение о сильном разбросе исчезнет. |
| `geometric.py:509,831` | Допуск остатка наклонной плоскости `max(0,12, 2,5 × noise)` | 1,783 → 0,12 мм. Ложные плоскости сложнее принять. |
| `bore_stitch.py:392` | Допуск поиска стенки `max(tol, noise)`, штатно `tol=0,3` | Поиск переходит к 0,3 мм. На крупной сетке всё ещё нужна отдельная поправка на хорду. |
| `chipfill.py:45–51,509–511`, `geo_worker.py:226` | Порог `max(median + 6×MAD, tol/10)`. Воркер вызывает с собственным `tol=0,3` | Поле `noise_mm` напрямую порог не меняет. |
| `walls.py:33–36`, `regions.py:627,671–673,713–716` | Своя оценка шума или свидетельства из локальной геометрии | Замена только поля листа замеров напрямую эти места не меняет. |

Эти потребители используют одну величину для разных целей. В отчёте и сравнении можно применять `working_mm` с указанием источника. Для предупреждения о шуме нужен измеренный остаток. Применение рабочего резерва к воротам отверстий проверяется отдельно на студийных деталях. Патч конвейера в эту задачу не входит.

## Результаты

132 из 132 замеров с заданным шумом 0,05 и 0,20 мм на 11 деталях прошли ±20%. Рабочее значение совпало с исходной оценкой 20а во всех этих прогонах. На открытых фланце, втулке и кронштейне прежние оценки также сохранились.

На гладком бинарном STL сферы радиуса 20 мм с медианой ребра 3,01 мм измеренный остаток 0,0010 мм, округление 0,0000017 мм, рабочая оценка 0,052 мм по хорде. На тестовом параллелепипеде из 12 треугольников измеренный шум отсутствует в отчёте из-за нехватки окрестностей. Резерв 0,408 мм отражает шаг этой чрезвычайно редкой сетки.
