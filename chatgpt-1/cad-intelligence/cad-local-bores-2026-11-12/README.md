# Задача 17б. Точные стенки отверстий после выбора ступени 0к

Патч добавляет экспериментальный режим `CAD_BORE_STITCH=1`. Он работает на гладком теле после выбора ступени и скруглений. По исходному скану проверяется наличие цилиндрической стенки, затем на рёбрах тела ищутся два замкнутых обода. Между ними заменяется локальная группа граней. Новый участок состоит из точного цилиндра и переходных линейчатых граней. Непересекающиеся участки сшиваются за один проход, при откате пакета возможны отдельные попытки. [Open CASCADE Sewing](https://occt3d.com/dev/doc/refman/html/class_b_rep_builder_a_p_i___sewing.html) · [Open CASCADE BRepFill](https://occt3d.com/dev/doc/refman/html/class_b_rep_fill.html)

Приёмка кандидата проверяет замкнутую валидную оболочку, ориентацию и положительный объём, допуски рёбер, точную внутреннюю цилиндрическую грань по оси, радиусу и протяжённости и прирост граней не более 10% от исходного тела. Покрытие проверяется в обоих направлениях на сыром скане и от очищенного скана к телу. В каждой метрике 4000 точек с фиксированным seed и порог 0,3 мм. Шум из `sheet.json` может расширить допуск при поиске исходной стенки. При нуле принятых стенок срабатывает штатный `cut_holes`. После успешной сшивки оставшиеся отверстия пропускаются в этом экспериментальном режиме. Лимит 45 секунд проверяется между попытками.

## Проверка на синтетике

| Деталь | Точных стенок по эталонному STEP | Граней после штатного выреза → после сшивки | Штатный вырез → сшивка, с |
| --- | ---: | ---: | ---: |
| Корпус с рёбрами | 0 → 3 из 3 | 1088 → 971 | 44,9 → 34,2 |
| Плита с четырьмя отверстиями | 0 → 4 из 4 | 1110 → 873 | 45,4 → 13,7 |
| Плита с цековками | 0 → 2 из 4 | 1125 → 1042 | 8,4 → 10,7 |

Проверка сделана после повторного открытия STEP. Все три результата валидные и замкнутые. Покрытие у корпуса выросло с 94,55% до 94,98% в направлении от скана к телу и с 95,98% до 96,33% в обратном. На двух плитах покрытие сохранилось. В плите с цековками детектор нашёл две нижние стенки. Верхние ступени цековок остались сплайнами. На синтетическом пазе проверка круглой стенки отвергла ложный кандидат, на детали со сферическим концом детектор кандидатов не выдал. На открытом тестовом кронштейне ни одна замена не прошла приёмку.

Данные в `synthetic-results.json` включают время, топологию и причины откатов. Время на синтетике измеряется для обработки отверстий на одном и том же готовом теле. При откате скрипт одной ступени прибавляет время эксперимента к измеренному штатному вырезу. На студийной детали основная команда делает два полных прогона 0к. Штатный selftest прошёл. Отдельный тест smooth-воркера с готовой ступенью подтвердил включение флага, переход к штатному вырезу при откате и штатный путь при выключенном флаге.

## Прогон на студийном кронштейне

Из корня `studio-exchange` применить патч в рабочей копии CAD-демо и запустить в Python-окружении проекта.

```powershell
$task = "chatgpt-1/cad-intelligence/cad-local-bores-2026-11-12"
git apply --check "$task/17b-local-bores.patch"
git apply "$task/17b-local-bores.patch"
python "$task/benchmark_local_bores.py" --demo claude/cad-demo --scan "D:/local/studio-bracket/scan_aligned.stl" --sheet "D:/local/studio-bracket/sheet.json" --work "D:/local/task17b" --face-cap 1776
```

Скрипт делает два последовательных прогона того же `geo_worker.py smooth` с одним сканом и диагностикой. Оба прогона без кэша поверхности и отверстий, с выключенными `CAD_HOLE_PLUG` и `CAD_ANALYTIC_BORES`. Остальные флаги, включая `CAD_FILLETS`, берутся из окружения. Для сравнения со студийным замером оставьте те же настройки, что использовались на нём. Результат в `studio-local-report.json`, логи и STEP лежат рядом. Код выхода 0 означает, что все проверки прошли. JSON отдельно содержит счётчики и полное время обоих прогонов. В студийном режиме покрытие дополнительно проверяется при 0,2 мм.

Для быстрой проверки одной ступени можно добавить `--stage-index 0` (индекс в `nurbs.STEPS`) или `--stage-step "D:/local/selected-before-holes.step"` (готовое тело непосредственно перед обработкой отверстий). Эти режимы сравнивают время обработки отверстий. Полное время 0к проверяется основной командой. Для независимой проверки радиусов и осей по эталону добавьте `--reference` с эталонным STEP, если он есть.

Порог студийной приёмки из задания — больше 0 точных стенок из 6, максимум 1776 граней, одно валидное замкнутое тело, покрытие и полное время 0к не хуже базового прогона. Студийный скан хранится у Компаса, его результат ещё предстоит получить.

## Повтор синтетики

```powershell
python "$task/benchmark_local_bores.py" --demo claude/cad-demo --case ribbed_housing --work "D:/local/task17b-ribbed"
python "$task/benchmark_local_bores.py" --demo claude/cad-demo --case drilled_plate --uniform --work "D:/local/task17b-drilled"
```

Вторая команда использует Gmsh только для подготовки равномерной синтетической сетки. Патч демо использует установленные зависимости. Для плиты с цековками подставьте `--case counterbored_plate`. Кэш готовой ступени можно использовать через `--reuse --refresh-baseline`, чтобы штатный вырез и сшивка выполнялись последовательно в одном замере. Команды работают без запросов к ИИ.
