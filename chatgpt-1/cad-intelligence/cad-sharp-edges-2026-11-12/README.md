# Задача 21а. Прямолинейные рёбра, пазы и окна в 0к

Патч добавляет опытный маршрут `CAD_SHARP_LAYOUT=1`. По нормалям треугольников оцениваются три взаимно перпендикулярных направления. Положения плоскостей измеряются по связным участкам скана. Из этих плоскостей строится пространственная раскладка. Пробы внутри ячеек определяют материал, а общие границы соседних ячеек образуют прямые рёбра. Грани сшиваются и объединяются в одной плоскости.

Маршрут рассчитан на детали с преобладанием плоскостей трёх направлений. На кривых или произвольно наклонённых поверхностях остаётся штатная сплайновая раскладка. В отрицательных проверках кандидат не строился на крышке двойной кривизны, торе и кронштейне 20б. Геометрия этих деталей требует другого способа сохранения рёбер.

Перед заменой штатного 0к проверяются одно валидное замкнутое тело, предел +15% граней и двустороннее покрытие сырого скана. Допуск последней проверки `max(0,3 мм, 3 × шум)`, разрешена разница в одну пробу из 4000. При ненулевом повышении допуска отчёт отдельно сохраняет сравнение при 0,3 мм. Например, у пластины 1,4 мм с шумом 0,20 мм покрытие сырого скана при фиксированных 0,3 мм снизилось с 96,6% до 94,5%. Сравнение с независимым CAD-эталоном при том же допуске выросло с 98,94% до 99,99%.

Опытная раскладка формирует границы отверстий и пазов напрямую. При её выборе эвристики цилиндрического выреза и скругления пропускаются. Это сохраняет прямоугольное окно: в контрольном запуске старый поиск отверстий после раскладки принял окно за круглый вырез Ø29,1 мм.

## Проверка

Пластина 87 мм и деталь 50 мм, на каждой пазы 3×12 и 4×20 мм, окно 25×25 мм и уступы 1–2 мм. Медиана ребра до шума 1,35–1,36 или 2,20–2,21 мм, наклон 6° или 9°, шум 0,05 или 0,20 мм. Все восемь случаев сравнивают STEP после повторного открытия с независимым эталоном при 0,3 мм. Штатная база — `nurbs.smooth_body` на том же скане до последующих вырезов.

## Запуск

Из корня репозитория в окружении CAD-демо. Патч накладывается отдельно или после 21б. Для генерации синтетики нужен `gmsh==4.15.2`.

```powershell
$task = "chatgpt-1/cad-intelligence/cad-sharp-edges-2026-11-12"
git apply --check "$task/21a-sharp-layout.patch"
git apply "$task/21a-sharp-layout.patch"
python "$task/benchmark_sharp_layout.py" --demo claude/cad-demo --work "D:/local/task21a"
$env:CAD_SHARP_LAYOUT = "1"
python claude/cad-demo/geo_worker.py "D:/local/bracket/scan_aligned.stl" "D:/local/bracket/sheet.json" 1 "D:/local/bracket/21a.json" smooth
```

Для проверки на студийных кронштейне и кнопке берите выровненный скан и лист замеров из одного прогона. Решение маршрута и покрытие записываются в `meta.sharp_layout`. Режим выключен по умолчанию.
