# Задача 18. Оценка шума скана на кривых деталях

`scan_noise.estimate(mesh)` принимает сетку в миллиметрах после штатного выравнивания. Возвращает предлагаемое значение `noise_mm`, метод и диагностические показатели. `scan_noise.noise_estimate(mesh)` возвращает число или `None` при недостатке данных. Подключение к конвейеру и выбор порогов остаются за Компасом.

- `support_plane`. Сохраняет прежний расчёт разброса Z центров треугольников после проверки, что есть достаточно большая опорная площадка, а квадратичная модель не объясняет разброс лучше плоскости. Дополнительная проверка по локальным участкам отсекает кривую полосу, которая выглядит плоской по общему распределению Z.
- `local_quadratic`. Для 2048 воспроизводимо выбранных вершин берёт по 32 точки со связного участка сетки, чтобы тонкая оболочка не подмешивала соседнюю стенку. В локальной касательной системе вычитает квадратичную поверхность, затем берёт 40-й процентиль локальных оценок СКО. Плохо обусловленные и почти объёмные окрестности отбрасываются. [Cazals и Pouget, локальная полиномиальная аппроксимация поверхности](https://diglib.eg.org/items/162a3809-5e38-480d-9739-4c5155313fd3)
- `insufficient`. При отсутствии подходящей плоскости и достаточного числа локальных участков возвращает `None`.

Для сравнения с известной добавленной погрешностью есть поле `vertex_sigma_mm`. Штатная плоская ветка считает разброс усреднённых центров треугольников. При независимом смещении вершин этот разброс обычно меньше вершинного σ. Поэтому в таблице приведены обе величины. Локальная оценка описывает вариации на масштабе нескольких рёбер сетки и может включать мелкую реальную геометрию. Она не измеряет систематический сдвиг скана относительно эталона.

## Синтетика с известным шумом

В каждой ячейке `noise_mm / vertex_sigma_mm`, мм. Медиана трёх прогонов для каждого уровня. Сетки из CAD-эталонов задач 9 и 11 подготовлены с целевым шагом 1 мм. В координаты вершин добавлен независимый гауссовский шум. Дополнительно проверена полная сфера без опорной грани. [Руководство Gmsh](https://www.gmsh.info/doc/texinfo/gmsh.html)

| Деталь | σ = 0 | σ = 0,05 | σ = 0,20 |
| --- | ---: | ---: | ---: |
| Скруглённая оболочка | 0,001 / 0,000 | 0,031 / 0,052 | 0,198 / 0,198 |
| Корпус с рёбрами | 0,009 / 0,009 | 0,060 / 0,060 | 0,229 / 0,229 |
| Коническая втулка | 0,002 / 0,001 | 0,029 / 0,050 | 0,199 / 0,199 |
| Сферический торец | 0,000 / 0,000 | 0,029 / 0,050 | 0,197 / 0,197 |
| Крышка двойной кривизны | 0,000 / 0,000 | 0,047 / 0,047 | 0,189 / 0,189 |
| Плита с отверстиями | 0,001 / 0,000 | 0,029 / 0,051 | 0,200 / 0,201 |
| Тор | 0,005 / 0,005 | 0,049 / 0,049 | 0,196 / 0,196 |
| Блок с пазом | 0,000 / 0,000 | 0,028 / 0,052 | 0,206 / 0,206 |
| Плита с цековками | 0,000 / 0,000 | 0,029 / 0,052 | 0,207 / 0,207 |
| Ступень со скруглениями | 0,001 / 0,000 | 0,029 / 0,054 | 0,213 / 0,212 |
| Полная сфера | 0,000 / 0,000 | 0,048 / 0,048 | 0,192 / 0,192 |

Крышка, тор и полная сфера во всех 27 прогонах пошли по локальной ветке. На ненулевых уровнях максимальная относительная ошибка этих трёх деталей 5,6%. Во всей синтетике 65 из 66 замеров с ненулевым шумом уложились в ±20% по `vertex_sigma_mm`. Один прогон ребристого корпуса дал 0,061 мм при заданных 0,05 мм. На шаге 1,5 мм чистый тор дал остаток 0,019 мм из-за кривизны, которая не укладывается в локальную квадратику на таком масштабе. Уровни 0,05 и 0,20 мм на шаге 0,7 и 1,5 мм прошли проверку ±20% для всех трёх кривых деталей.

На оболочке из 1 000 000 треугольников оценки 0,048 и 0,190 мм при заданных 0,05 и 0,20 мм. Расчёт занял 2,48 и 2,39 с на Windows с Python 3.12.10 и одним потоком OpenBLAS. Время включает построение графа и поиск окрестностей на уже загруженной сетке. [Данные прогонов](results.json)

## Повтор прогона

Из корня `studio-exchange` в Python-окружении CAD-демо. Для генерации синтетики понадобится `gmsh==4.15.2`. Для измерения уже имеющихся сканов модуль оценки использует NumPy и SciPy.

```powershell
$task = "chatgpt-1/cad-intelligence/cad-scan-noise-2026-11-12"
$env:OPENBLAS_NUM_THREADS = "1"
python "$task/benchmark_scan_noise.py" --demo claude/cad-demo --seeds 3 --million --output "D:/local/noise-synthetic.json"
python "$task/benchmark_scan_noise.py" --demo claude/cad-demo --skip-suite --aligned --scan hyundai "D:/local/hyundai/scan_aligned.stl" --scan lens "D:/local/lens/scan_aligned.stl" --scan bracket "D:/local/bracket/scan_aligned.stl" --expect-support lens --expect-support bracket --output "D:/local/noise-studio.json"
```

Для исходного скана уберите `--aligned`, чтобы стенд вызвал штатное выравнивание. Код выхода 1 означает, что не пройдена хотя бы одна проверка. JSON записывается и при таком результате. Проверки по умолчанию включают ±20% на кривых синтетических деталях с ненулевым шумом, остаток ≤0,012 мм на их чистых версиях, ±20% к старой оценке на явно заданных опорных сканах и ≤5 с на миллионе треугольников.
