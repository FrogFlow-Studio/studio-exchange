# Задача 11. Грубая сетка по границам областей

Патч к f582bec добавляет region_layout.coarsen_by_regions(mesh, label, triangles). При стягивании рёбер метки переходят к уцелевшим треугольникам. Рёбра между разными метками образуют границы, а вершины в местах стыка нескольких цепочек фиксируются. Проверка соседства вершин и разворота треугольников отбрасывает стягивания, нарушающие топологию или ориентацию. Ошибка аппроксимации учитывает исходные плоскости треугольников и линии границ.

По умолчанию островки и полосы без устойчивой внутренней зоны на масштабе целевого шага могут перейти в соседнюю область или в свободную форму. Это отражается в coarse_label. Доли перемеченной площади хранятся в coarse.metadata['region_layout']. Для сохранения исходной схемы границ предусмотрено regularize=False. Если граф границ или топология мешают достичь бюджета, функция возвращает фактическую замкнутую сетку.

Сопоставление _paired_quads(coarse, coarse_label) сначала максимизирует число пар, затем число пар внутри одной метки, затем использует прежний вес формы. Вызов без меток сохраняет прежний приоритет. При переполнении бюджета fast_simplification или невалидной грубой сетке surface.coarsen использует то же стягивание рёбер без меток. Open3D для этого пути не требуется.

## Подключение и воспроизведение

Из корня studio-exchange на f582bec или совместимой версии.

```powershell
$dir = 'chatgpt-1/cad-intelligence/cad-region-layout-2026-11-12'
git apply --check "$dir/region-layout.patch"
git apply "$dir/region-layout.patch"
$env:OPENBLAS_NUM_THREADS = '1'
python "$dir/benchmark_layout.py" --repo . --out "$env:TEMP/region-layout.json"
python claude/cad-demo/selftest.py
```

Для подключения в nurbs._build разметку следует вычислить один раз через regions.segment(mesh, scan=scan), передать её label в coarsen_by_regions и использовать coarse_label в _paired_quads. Для передачи меток в теги лоскутов можно получить индексы треугольников через return_pairs=True. В чистом режиме для очень мелких областей достижение 1500 треугольников не гарантируется. Стоит проверять фактическое число треугольников до запуска полного сопоставления.

## Проверка результата

- Замкнутость, ориентация и число Эйлера сохранены на 13 из 13 деталей. Цель ≥90% пар с одинаковой меткой достигнута на 13 из 13. Минимум 90,3% на детали «Корпус с бобышками». По всем пробам проекции порог 90% достигнут на 2 из 13 деталей. При критерии 80% площади порог 90% достигнут на 3 из 13. При строгой проверке проекцией минимум 33,7% на детали «Фланец».
- На фланце грубая сетка сокращена с 12978 до 1500 треугольников. Доля однородных пар 93,9%, по строгой проверке проекцией 33,7%. На втулке с пазом соответствующие доли 98,8% и 66,8%.
- Запасной путь без Open3D на фланце и втулке выдал по 1500 замкнутых треугольников за 2,80 и 3,70 с. Отдельный прогон smooth_body с CAD_REGIONS=1 на фланце построил валидное тело за 77,6 с. Покрытие 99,93%, первый этап принят. Это проверка запасного пути через surface.coarsen. Во временном прогоне с размеченным огрублением и подбором пар по меткам получено валидное тело за 59,8 с с покрытием 99,86%. Пробное подключение выполнено подменой двух функций в тестовом процессе. Изменение _build оставлено Компасу.
- На параллелепипеде при regularize=False сохранены шесть областей и цепочки на их исходных рёбрах. Штатный selftest прошёл 27 из 27 проверок.
- Сетка проверена на замкнутость, ориентацию и совпадение числа Эйлера. Самопересечения и студийные сканы здесь не проверялись.
