# 04. Запуск и качество

Строим полный продукт (решение Якова). Ниже как измерять качество и как выводить на рынок, чтобы к готовому продукту пришли пользователи.

## Эталон качества генерации

- Набор из 100+ реальных заказов на ботов (биржи фриланса, чаты предпринимателей, заказы знакомых), разложенный по нишам.
- Каждый релиз генератора прогоняется по всему набору: доля «собрано без правок», «1–2 правки», «не собирается», время и стоимость генерации.
- Цель к запуску: 80 % без правок для типовых ниш. Ниже 70 % — релиз генератора не выпускаем.
- Набор пополняется настоящими запросами пользователей (обезличенно).

## Метрики продукта

| Метрика | Цель [гипотеза] |
| --- | --- |
| Время от описания до работающего бота | < 10 минут |
| Доля новых пользователей, опубликовавших бота | > 40 % |
| Пробный → платный | > 10 % |
| Отток в месяц | < 5 % |
| Боты без сбоев за месяц | > 99 % |
| Себестоимость генераций / выручка | < 20 % |

## Выход на рынок

1. **Лист ожидания с первого дня разработки:** лендинг с видео, анонсы в чатах ботоделов и предпринимателей KZ, KG, UZ.
2. **Закрытая бета** со студиями и ботоделами: бесплатный доступ за обратную связь и кейсы.
3. **10 разговоров с ботоделами** до начала слоя 3 (кабинет студий): как они работают, за что платят.
4. **Публичный запуск** с шаблонами по 20 нишам и кейсами беты.
5. **Партнёрская программа** для студий: процент с клиентов, которых они привели.
6. **Связка с ENVERIQ:** кто в Botaqan продаёт много, тому предлагаем ENVERIQ, и наоборот, клиентам ENVERIQ с задачами вне продаж — Botaqan.
