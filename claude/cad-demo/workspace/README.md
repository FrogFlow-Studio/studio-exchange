# CAD Intelligence. Локальное рабочее окно

Запускается из корня studio-exchange с тем же Python, которым запускается CAD-демо. Пакеты берутся из `claude/cad-demo/requirements.txt`.

```powershell
python chatgpt-1/cad-intelligence/cad-workspace/server.py
```

Приложение открывает [локальное окно](http://127.0.0.1:8770/). Можно выбрать другой порт через `--port`, каталог данных через `--data`, отключить открытие браузера через `--no-open`. По умолчанию расчёты сохраняются в `FrogFlow/CAD Workspace` внутри `LOCALAPPDATA` на Windows. `Ctrl+C` закрывает сервер.

При первом запуске открыт сохранённый расчёт специально повреждённого тестового фланца. `example.zip` содержит STEP и сетку, построенные реальным маршрутом 0ж на `ec53aad2ef89fb8bbe1fd05b93954fa75c645550`, макрос SolidWorks и матрицу из листа замеров этого прогона. Проверка по эталону даёт 12 из 12 элементов в допуске. Исходный скан и эталон берутся из `claude/cad-demo/samples`. Хеш STEP хранится внутри архива. Кнопка «Пересчитать» создаёт новый запуск с тем же сканом.

- «Открыть скан» или перетаскивание в сцену принимает STL, OBJ и PLY. После загрузки можно проверить габариты, выбрать единицы и построить модель.
- Расчёт вызывает штатный `demo.py --mode geometric`. Строка состояния показывает этап, прошедшее время по сообщению движка и попытки, сравнение которых со сканом завершилось. Флажок «Точные грани по разметке (опытный)» задаёт `CAD_REGIONS` для нового запуска. Версия движка и запрошенное состояние флажка видны в истории и в JSON-отчёте. Пайплайн выбирает маршрут по скану, поэтому простой фланец может завершиться по 0ж при любом значении флажка.
- Готовый расчёт открывается в режиме «Рядом». Исходный скан и CAD-модель вращаются, масштабируются и отсекаются общей камерой. В меню «Ракурс» доступны шесть ортогональных видов и изометрия. На узком экране окна расположены одно над другим. Кнопка «Сечение» включает общую отсечку по X, Y или Z и показывает координату плоскости. Сторону отсечки можно перевернуть. Режим «Отклонения» показывает два направления. «Модель → скан» красит треугольники поверхности по расстоянию от их центров до скана. «Скан → модель» показывает цветные пробы на скане. Шкала насыщается при двойном допуске.
- «Замер» показывает расстояние между двумя точками одной сетки в миллиметрах. Это инструмент осмотра тесселяции.
- Панель проверки содержит сводку, геометрию STEP и приёмку по эталону. Из сводки можно сразу открыть карту отклонений в нужном направлении.
- Повторные расчёты от одной загрузки видны в истории как версии проекта. Готовые версии в одних единицах можно сравнить по метрикам проверки и открыть по отдельности. Покрытие сравнивается при совпадающем допуске.
- В «Приёмке» можно сохранить решение и комментарий для конкретного STEP. Решение хранится локально вместе с расчётом. При пересчёте начинается новая приёмка.
- В режиме «Наложение» янтарным отмечаются треугольники модели, чьи центры дальше допуска от скана. Эта отметка описывает покрытие сканом. Причина отсутствия измерений может быть разной.
- Проверка отдельно показывает повторное чтение STEP, топологию и двустороннее отклонение. Для тестового фланца есть эталон и замечания с пространственной привязкой к центру проверяемой грани. Для других сканов интерфейс сообщает об отсутствии эталона. Отчёт проверки скачивается в JSON. В блоке «Тело» видны количества плоскостей, цилиндров, B-сплайнов и остальных граней по повторно открытому STEP. Макрос SolidWorks доступен рядом с STEP, когда движок его сформировал.

Просмотрщик показывает тесселяцию STEP. Сечение служит для осмотра, а редактирование B-rep и дерево построения остаются в CAD. Интерфейс запускает один расчёт за раз и слушает только адрес `127.0.0.1`. Существующие файлы CAD-демо находятся в папке Компаса. Просмотрщик использует те же локальные модули Three.js.
