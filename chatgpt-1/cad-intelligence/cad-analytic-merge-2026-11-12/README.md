# Задача 14. Объединение соседних аналитических граней

[Патч](merge_analytic.patch) добавляет `merge_analytic(shape, tol) -> (shape, report)` для объектов `cadquery.Shape`. Допуск задаётся в единицах модели, в стенде — 0,001 мм. Для осей и нормалей угловой допуск вычисляется из линейного допуска и диагонали тела. Слияние рассматривается только по общему ребру для плоскостей, цилиндров, конусов и сфер с совпадающими параметрами. В результате проверяются параметры всех объединённых граней, топологическая идентичность защищённых граней, валидность, замкнутость, число тел и оболочек, а также изменение объёма каждого тела в пределах 0,1%. Если проверка не проходит, возвращается исходный объект с причиной отката. [Документация Open CASCADE по UnifySameDomain](https://dev.opencascade.org/doc/refman/html/class_shape_upgrade___unify_same_domain.html)

На синтетике из задач 9 и 11 эталонные тела разрезали поперёк и снова соединили с сохранением швов. Из 190 граней осталось 138. Восемь тел упростились, у крышки и тора изменяемых граней не было. Число пар в допуске и лишних признаков на всех деталях совпало. Стенд задачи 12 сам группирует смежные грани на совпадающих опорах, поэтому сокращение видно в числе граней STEP. Все результаты после повторного чтения STEP валидны и замкнуты, максимальное изменение объёма при слиянии до записи STEP — около 6,1×10⁻¹⁵ относительно исходного.

Отдельные регрессии подтвердили слияние каждого из четырёх поддерживаемых типов, сохранение настоящих B-сплайнов и сохранение свободной формы на том же теле при слиянии плоскостей. Проверены раздельные тела, разные радиусы, повторный вызов и оба отката — по невалидности и по превышению изменения объёма. `selftest.py` завершился успешно на Python 3.12, Python 3.10 и 3.11 локально отсутствуют. Весь прогон выполнен без платного ИИ.

На кронштейне 0ж у соседних фрагментов бобышки разные радиусы и положения осей. Например, смежные фрагменты имеют R13,0421 и R13,0306 мм с расстоянием между параллельными осями около 0,0166 мм. При допусках 0,02 и 0,05 мм ядро предлагает изменения, которые откатываются по валидности. На шаге 0к фланца `(1500, 17, 10)` с `CAD_REGIONS=1` на этой базе нашлось 16 граней R44,995 мм с нулём общих рёбер между ними. Их границы примыкают к сплайновым лоскутам.

Для сокращения граней на этих двух примерах придётся изменить построение. Для 0ж — оценить общие радиус и ось бобышки по нескольким сечениям до построения слоёв. Для 0к — изменить границы аналитической области до сшивки, чтобы части цилиндра получили общие рёбра. Оба изменения требуют отдельной проверки размеров по эталону.

## Воспроизведение

База `3a2dd20afe0b964b0da8a22d6ec05f322f34ec93`. Патч применяется из корня checkout. Команды запускаются в окружении CAD-демо с Python 3.12, CadQuery 2.8 и OCP 7.9.3. В `$artifact` укажи абсолютный путь к этой папке, в `$runs` — новый каталог для результатов.

```powershell
git apply --check "$artifact/merge_analytic.patch"
git apply "$artifact/merge_analytic.patch"
Set-Location claude/cad-demo
$env:PYTHONUTF8 = '1'
$env:CAD_SMOOTH_BACKGROUND = '0'
$env:OPENBLAS_NUM_THREADS = '1'
python selftest.py
foreach ($case in 'flange','bushing','bracket') {
  python demo.py ("samples/{0}_scan.stl" -f $case) --mode geometric --no-open --out "$runs/$case"
}
python "$artifact/benchmark_merge.py" --demo . --sample-runs $runs --output "$runs/results.json"
```

Чтобы повторить отдельную строку 0к, возьми `scan_aligned.stl` из прогона фланца и выполни из каталога CAD-демо при `CAD_REGIONS=1`. Переменные `scan_path` и `step_path` — пути к входному STL и выходному STEP соответственно.

```python
import cadquery as cq
import nurbs
import surface
import trimesh

scan = trimesh.load(scan_path, force="mesh")
mesh = surface.flatten_planes(surface.surface_mesh(scan))
nurbs._SCAN = scan
triangles, nurbs.K, nurbs.NP, nurbs.PAIR = nurbs.STEPS[0]
body, _, _ = nurbs._build(mesh, triangles, nurbs._Projector(mesh), profile={}, stage={})
cq.exporters.export(body, step_path)
```

Передай STEP через `--smooth-stage`. Для этой строки стенд задачи 12 измеряет топологию и пары аналитических граней по обрезанным поверхностям. Замер облаком точек пропущен. Для 0ж и синтетики выполнено также двустороннее сравнение поверхностей с эталоном. [Числа и отчёты откатов](results.json).
