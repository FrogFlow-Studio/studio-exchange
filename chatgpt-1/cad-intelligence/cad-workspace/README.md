# CAD Intelligence. Локальное рабочее окно

Запускается из корня studio-exchange с тем же Python, которым запускается CAD-демо. Пакеты берутся из `claude/cad-demo/requirements.txt`.

```powershell
python chatgpt-1/cad-intelligence/cad-workspace/server.py
```

Приложение открывает [локальное окно](http://127.0.0.1:8770/). Можно выбрать другой порт через `--port`, каталог данных через `--data`, отключить открытие браузера через `--no-open`. По умолчанию расчёты сохраняются в `FrogFlow/CAD Workspace` внутри `LOCALAPPDATA` на Windows. `Ctrl+C` закрывает сервер.

При первом запуске открыт сохранённый расчёт специально повреждённого тестового фланца. `example.zip` содержит STEP и сетку, построенные реальным маршрутом 0ж на `f582bec6644a067ea53e7442640f556151002414`, и матрицу из листа замеров этого прогона. Исходный скан и эталон берутся из `claude/cad-demo/samples`. Хеш STEP хранится внутри архива. Кнопка «Пересчитать» создаёт новый запуск с тем же сканом.

- «Открыть скан» или перетаскивание в сцену принимает STL, OBJ и PLY. После загрузки можно проверить габариты, выбрать единицы и построить модель.
- Расчёт вызывает штатный `demo.py --mode geometric`. Состояние берётся из хода реального запуска. Каждый запуск имеет свой каталог, а интерфейс сохраняет их в истории.
- Общая камера сохраняется при переключении режима 3D. Кнопка «Сечение» включает горизонтальную отсечку. Режим «Отклонения» раскрашивает пробы расстояния от скана до тесселяции модели.
- В режиме сравнения янтарным отмечаются треугольники модели, чьи центры дальше допуска от скана. Подсветка доступна для сеток модели до 15 тысяч треугольников. Эта отметка описывает покрытие сканом. Причина отсутствия измерений может быть разной.
- Проверка отдельно показывает повторное чтение STEP, топологию и двустороннее отклонение. Для тестового фланца есть эталон и замечания с пространственной привязкой к центру проверяемой грани. Для других сканов интерфейс сообщает об отсутствии эталона. Отчёт проверки скачивается в JSON.

Просмотрщик показывает тесселяцию STEP. Сечение служит для осмотра, а редактирование B-rep и дерево построения остаются в CAD. Интерфейс запускает один расчёт за раз и слушает только адрес `127.0.0.1`. Существующие файлы CAD-демо находятся в папке Компаса. Просмотрщик использует те же локальные модули Three.js.
