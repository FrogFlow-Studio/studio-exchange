# Задачи 49–52. Путь 0с для кнопки

Стенд создаёт собственный STEP корпуса с наружным размером около 23×49×13 мм, стенкой и двумя перегородками толщиной 1,2 мм, двумя полыми бобышками, пазом и язычком, выпуклостью дна и скруглением R0,48. К сетке добавляется воспроизводимый нормальный шум σ 0,05 и 0,1 мм. Для 52 отдельно создаются три CAD-модели с внесёнными дефектами.

Из корня общего репозитория, в окружении CAD-демо с VTK и Matplotlib.

```powershell
$task = 'chatgpt-1/cad-intelligence/cad-kompas-button-2026-11-13'
$env:PYTHONPATH = "$task;claude/cad-demo;claude/cad-demo/kompas"
python "$task/benchmark_button.py" --work "$env:TEMP/sever-button"
python "$task/benchmark_button.py" --work "$env:TEMP/sever-button" --assembly
```

Локальный запуск сборки использует `button_trial.assemble` и тот же порядок операций, что в 0с. Обёртка использует прямой вызов OCC для лофта под Windows, где исходный процесс с методом `fork` недоступен. Флаги `detect`, `round_edge`, `raised_rim`, `fixed_rings` выключены по умолчанию. Функции можно вызывать по отдельности. Сравнение использует STL с проверкой объёма. При отклонении объёма свыше 5% строка возвращает `coverage: null`.

- `button_defects.defects` возвращает пятна по двум направлениям сравнения. Знак измеряется вдоль нормали ближайшего треугольника другой поверхности. Список видов учитывает ориентацию нормалей по восьми направлениям листа. Перекрытие пятна другими частями детали в конкретном ракурсе пока не проверяется.
- `bottom_round.estimate_radius` подгоняет четверть окружности по изменению площади нижних сечений. `round_bottom` пробует оценённый радиус и два уменьшенных радиуса. Рёбра выбираются по высоте вершин. При отказе OCC остаётся исходное тело.
- `rim_fit.fit_rim` агрегирует измерения по длине корпуса и сглаживает кубической функцией с ограничением области экстраполяции. Модель предполагает, что подъём зависит преимущественно от продольной координаты.
- `ring_fit.correspond` измеряет все кольца на одних лучах и сглаживает радиус вдоль высоты. Сильно неоднозначные сечения отклоняются. График показывает максимум второй производной координат кольца по высоте, это диагностическая мера для продольного профиля.
