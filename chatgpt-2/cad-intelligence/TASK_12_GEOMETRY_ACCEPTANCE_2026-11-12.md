# Северу: задача 12. Независимая проверка геометрической точности B-rep

**Приоритет:** высокий  
**Тип:** исследовательская задача / тестовая инфраструктура  
**Зависимость:** выполнять после завершения текущей задачи по сохранению границ регионов (coarsen_by_regions), либо согласовать с Компасом возможность независимой разработки стенда.

## Цель

Создать независимый стенд, который проверяет, насколько точно CAD Intelligence восстанавливает инженерные геометрические элементы. Валидное B-rep-тело и высокое покрытие поверхности сами по себе не доказывают правильность восстановленных отверстий, плоскостей, цилиндров, конусов и скруглений.

## Объём работ

1. Создать отдельный модуль проверки, не меняя основной алгоритм реконструкции без согласования с Компасом.
2. Использовать детали с известной исходной CAD-геометрией и сравнивать параметры восстановленных элементов с эталоном.
3. Проверять:
   - число цилиндрических отверстий и других цилиндров;
   - радиусы, оси, центры и направления цилиндров;
   - положение, ориентацию и отклонение плоских поверхностей;
   - параметры конусов, если они поддерживаются текущим маршрутом;
   - скругления, если они распознаются;
   - валидность, замкнутость и связность итогового B-rep.
4. Раздельно учитывать пропущенные элементы, ложные обнаружения и ошибки параметров.
5. Сохранять машиночитаемые результаты и понятный отчёт по каждой детали.

## Набор тестов

Начать с доступных эталонных моделей:
- тестовый фланец;
- тестовая втулка;
- линза студии;
- кронштейн студии;
- Hyundai.

Если эталонная CAD-модель для конкретного скана отсутствует или не соответствует скану, явно пометить такой тест как непригодный для параметрической приёмки. Не подменять отсутствующий эталон предположениями.

## Методика

- Зафиксировать единицы измерения и допуски до запуска.
- Использовать одинаковую методику для старого и нового маршрутов.
- Отдельно оценивать геометрию, топологию и покрытие/отклонение поверхности.
- Не считать элемент восстановленным только по факту наличия похожей грани: должны совпадать тип и параметры в заданных допусках.
- Результаты должны быть повторяемыми.
- Не менять производственные пороги и настройки ради улучшения отчётных цифр.

## Критерии приёмки

- Есть запускаемый скрипт `geometry_acceptance.py`.
- Есть тесты на доступных эталонных моделях.
- Для каждого элемента указаны эталонные и восстановленные параметры, ошибка и статус.
- Отдельно показаны пропуски, ложные элементы и ошибки параметров.
- Проверка B-rep включает валидность и замкнутость.
- Есть JSON-результат и Markdown-отчёт.
- В отчёте явно перечислены ограничения и тесты, для которых нет пригодного эталона.

## Ожидаемые артефакты

- `geometry_acceptance.py`;
- тестовые данные/конфигурация без дублирования больших бинарных моделей в репозитории;
- JSON с результатами;
- Markdown-отчёт с выводами.

**Важно:** задача должна измерять качество независимо от алгоритма реконструкции. Не объединять её с исправлениями основного конвейера без отдельного согласования.
