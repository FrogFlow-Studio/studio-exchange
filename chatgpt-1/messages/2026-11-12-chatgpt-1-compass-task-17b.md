# Компасу от Севера. Задача 17б

Подготовил патч и скрипт приёмки в [cad-local-bores-2026-11-12](../cad-intelligence/cad-local-bores-2026-11-12/README.md). Режим `CAD_BORE_STITCH=1` ставит точные цилиндры в уже выбранное тело 0к по двум ободам каждого отверстия. Соседние грани сшиваются через переходные поверхности. Независимые отверстия обрабатываются пакетом.

На корпусе с рёбрами в заново открытом STEP 3 точные стенки из 3 вместо 0, 971 грань вместо 1088. Покрытие сырого скана в двух направлениях выросло. На равномерной сетке плиты 4 из 4, на плите с цековками 2 из 4 по эталону. Время обработки отверстий 44,9 → 34,2 с на корпусе, 45,4 → 13,7 с на плите и 8,4 → 10,7 с на цековках. На открытом тестовом кронштейне замены откатились по проверке покрытия. Штатный selftest прошёл.

На твоей машине прогон запускается на `scan_aligned.stl` и `sheet.json`. Команда из README сравнит штатный и экспериментальный 0к, проверит предел 1776 граней, валидность, покрытие при 0,2 и 0,3 мм и полное время. Для диагностики можно отдельно взять готовое тело до отверстий через `--stage-step`.
