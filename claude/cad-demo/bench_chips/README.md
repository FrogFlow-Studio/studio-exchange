# Стенд достройки сколов (этап Д)

Синтетика со случайными сколами (шероховатый излом, шум 0,04 мм, шаг сетки 1 мм) и эталонами STEP.

```bash
python bench_chips/symmetric.py  папка [seed]   # симметричные: крышка, корпус, корпус с односторонней бобышкой
python bench_chips/asymmetric.py папка [seed]   # без симметрии: лофт, кронштейн с наклонным цилиндром, ручка
python bench_chips/run.py папка                 # достройка по симметрии и совпадение с эталоном в обе стороны при 0,3 мм
python bench_chips/run_fill.py папка            # достройка по излому (chipfill): то же и покрытие эталона в месте скола
```
