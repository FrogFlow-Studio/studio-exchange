# Задача 20б. Диагностика отверстий на крупной сетке

Стенд строит скан синтетического кронштейна с шестью отверстиями Ø7–35 мм, глубиной 1,8–6,3 мм и наклоном осей примерно 6,5–8,7°. Сетка содержит 14 868 треугольников. Медианное ребро 1,98 мм, p90 — 3,88 мм. Для сравнения у студийного кронштейна 2,01 и 4,06 мм. Шум вершин синтетики σ 0,05 мм. Замер выполнен на первой ступени 0к версии `d77e6de`.

Старая проверка фиксированным расстоянием от окружности до сетки подтверждает три из шести стенок, предложенных штатным `hole_parameters`. Лучи из оси отверстия дают подтверждение для шести. Проверка требует попаданий на ориентированные внутрь треугольники во всех секторах, допускает отклонение внутрь в пределах стрелы хорды и использует шум при оценке радиального зазора. На отдельной синтетике с овальным пазом радиальное подтверждение отсутствовало.

Пакетная сшивка построила пять стенок в пределах допусков эталона. После повторного открытия STEP получено одно валидное замкнутое тело, 770 граней вместо 740 (+4,1%). У шестой стенки стенд не нашёл пригодную пару ободов. В текущем опыте случай из студийного прогона с тремя гранями и невалидной сшивкой не воспроизвёлся.

| Покрытие при 0,3 мм | Исходная ступень | Опытная сшивка |
| --- | ---: | ---: |
| Сырой скан → тело | 87,800% | 88,575% |
| Тело → сырой скан | 91,675% | 92,100% |
| Очищенная поверхность → тело | 100,000% | 99,825% |

Прежний строгий критерий откатывает пакет по очищенной поверхности. В полном повторе семь из 4000 проб вышли за допуск. На сохранённой ступени отдельная трассировка локализовала шесть потерянных проб у отверстий Ø6,85, Ø8,33 и Ø17,41 мм. Проверка с той же защитой и радиальным методом только там, где старая проверка не дала стенку, оставила две точные стенки. Это промежуточный стенд для разбора потерь. Приёмка 20б открыта.
