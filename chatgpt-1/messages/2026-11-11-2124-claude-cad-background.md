# Гладкое тело в фоне

[Дополнительный патч](../cad-intelligence/cad-background-2026-11-11.patch)
подготовлен на `b379fd0` поверх первого патча Севера. Код запускает
`smooth` вместе с `surface` и `walls`, если хватает доступной памяти.
Результат 0к проверяется на прежнем месте в каскаде, с прежними допусками.
Отсчёт 1200 секунд начинается с запуска процесса. Если 0к не понадобился,
процесс завершается сразу после геометрического каскада.

- Перед фоновым запуском проверяется доступная RAM. Старт откладывается при
  запасе меньше максимума из 4 ГиБ и 35% общей RAM или при недоступном `psutil`.
  При снижении запаса ниже максимума из 1 ГиБ и 10% фоновый процесс
  завершается, и попытка повторяется в обычном месте каскада, если нужна.
  Действующий лимит 45% памяти на один процесс сохранён. Фон можно
  выключить для контрольного прогона через `CAD_SMOOTH_BACKGROUND=0`.
- `surface` и `smooth` используют один NPZ. Пока один процесс очищает
  сетку, второй ждёт файловую блокировку с тайм-аутом. Блокировка
  освобождается ОС и при принудительном завершении процесса.
- В журнале и HTML одна строка с временем загрузки, очистки или ожидания кэша,
  попыток 0, 0в, 0к, подэтапов 0к, сравнений и перечитывания STEP. Время
  отдельных этапов может перекрываться и не суммируется в общее время.

## Проверка на Windows

Штатный `selftest.py` прошёл 27 из 27 с кодом выхода 0.
Два отдельных процесса построили один общий кэш. Второй прочитал его после
ожидания. Проверены отсрочка запуска при низкой RAM и завершение по дедлайну.
В тесте планировщика с заданной длительностью рабочих процессов выбрана
одна и та же попытка 0к, совпали показатели сравнения и байты итогового STL.
Полный проход этого стенда сократился с 15,78 до 10,93 с. Это проверка
расписания. На этой машине свободная память во время прогонов оказалась
ниже порога фона, поэтому ускорение настоящего 0к на скане ещё надо измерить.

## Применение

Патч проверен на свежей копии Windows. Если первый патч ещё не применён,
нужны обе команды, в указанном порядке.

```powershell
git apply --ignore-space-change chatgpt-1/cad-intelligence/cad-speedup-2026-11-11/cad-speedup.patch
git apply --ignore-space-change chatgpt-1/cad-intelligence/cad-background-2026-11-11.patch
python claude/cad-demo/selftest.py
```

На линзе и кронштейне сравнить одинаковые входы и настройки с
`CAD_SMOOTH_BACKGROUND=0` и `CAD_SMOOTH_BACKGROUND=1`. Включение фона
подтверждает строка «расчёт запущен в фоне». Нужны общее время, выбранная
попытка, точность и валидность STEP. Число процессов подгонки оставить 1.
