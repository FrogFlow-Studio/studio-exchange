# Стенд разметки областей CAD

Патч к `da7feb1` развивает `regions.segment(mesh)`. Он добавляет затравки от круговых сечений, проверку дрейфа цилиндрической стенки и области двух новых видов. Запись сферы содержит `center` и `r`. Запись конуса содержит `apex`, `axis` и `semi_angle_deg`. Ось направлена от вершины в сторону увеличения радиуса. У обоих видов есть `faces`, `area` и `inner`.

## Как повторить

Команды выполняются из корня репозитория. Используйте окружение CAD-демо с CadQuery, Trimesh, SciPy и Rtree.

```powershell
$files = 'chatgpt-1/cad-intelligence/cad-regions-2026-11-12'
git apply --check "$files/regions.patch"
git apply "$files/regions.patch"
$env:OPENBLAS_NUM_THREADS = '1'
python "$files/benchmark_regions.py" --repo . --out "$env:TEMP/regions-bench.json"
python claude/cad-demo/selftest.py
```

Команды применения патча нужны на исходной версии. Если изменения уже внесены, начинайте с запуска стенда. Скрипт читает исходный сегментатор через `git show da7feb1:claude/cad-demo/regions.py` и измеряет обе реализации на одной очищенной сетке. Для выборочного прогона есть `--cases`, для другого случайного повреждения `--seed`. Числа ниже получены с seed `20261112` и допуском разметки 0,3 мм.

## Методика

- Три существующих STL/STEP из `samples/` и семь деталей CadQuery. Новые детали тесселированы, срезаны наклонной плоскостью со случайным азимутом и глубиной и зашумлены по XYZ с σ 0,05 и 0,2 мм. Для пары уровней шума используется один и тот же срез.
- Чистая сетка строится штатной `surface.surface_mesh`. Стенд сопоставляет центры её треугольников с ближайшей точкой на тесселированной **ограниченной** грани неповреждённого CAD. Треугольники дальше 0,6 мм от эталона получают отдельную метку повреждения. Припуск в 0,6 мм используется для проекции и не ослабляет допуски на параметры. У кромок такое соответствие приближённое.
- Полнота делит площадь корректно размеченных треугольников на видимую площадь эталонных аналитических граней. Точность делит её на площадь всех предсказанных аналитических областей. Площадь берётся по очищенной сетке. Полностью утраченная часть грани в полноту не входит.
- Плоскость сверяется по углу до 1° и смещению до 0,1 мм. Цилиндр сверяется по оси до 2°, радиусу и смещению оси до `max(0,1 мм, 2% R)`. Сфера сверяется по радиусу и центру с тем же допуском. Конус сверяется по направленной оси и полууглу до 2° и по смещению оси и радиусу до 0,3 мм в сечении на высоте центра эталонной грани. Ошибку удалённой вершины можно отдельно вычислить из координат в JSON.
- Область считается ложной, когда корректна максимум половина её площади. В площади ошибок учитываются и неверные участки остальных областей. Время измеряет только `segment`, включая его внутренние сечения и проверки. Сборка скана, очистка и сопоставление с эталоном в это время не входят.

## Приёмка и ограничения

- На фланце распознаны стенки всех пяти сохранившихся отверстий R4. Радиусы 3,897–3,904 мм. Строгую проверку радиуса и оси прошли 2 из 5. Пограничные ошибки оценены по исходным числам без округления. Область исходного ложного цилиндра R54,6 исчезла. Цилиндры R45, R22 и R12,5 сохранены.
- На конусной втулке полнота конусов 68,3% при σ 0,05 и 45,4% при σ 0,2 мм. На сферической детали полнота сферы 88,9% и 77,9% соответственно. Независимые чистые сетки смещённой сферы и наклонного конуса прошли проверку параметров.
- На крышке площадь ложных цилиндров 945 → 274 мм² при σ 0,05 и 29 → 136 мм² при σ 0,2. На торе 5138 → 1950 и 1680 → 1842 мм². На крышке при σ 0,05 общая ошибочно размеченная площадь выросла с 2051 до 6854 мм², главным образом из-за ложных сфер. Поэтому для этапа Б текущую разметку стоит использовать как гипотезы граней. Для автоматического построения рёбер нужно проверять эти гипотезы по соседней поверхности.
- Очистка отдельных STL вызывает ремонт сетки. На кронштейне и оболочке итоговый размер превышает целевые 20 тысяч треугольников. Стенд сохраняет фактический размер и сравнивает обе версии на одном результате очистки.
- Патч применён в отдельном worktree. CLI экспортировал PLY фланца с 19 998 треугольниками и четырьмя цветами. Штатный selftest прошёл 27 из 27 проверок. Студийные сканы и платный ИИ не использовались.
