# Задача 19. Разметка, покрытие и сшивка 0к

[Патч](regions_guard.patch) добавляет опытный режим `CAD_REGIONS_GUARD=1` при `CAD_REGIONS=1`. [Стенд](benchmark_region_guard.py) сравнивает одинаковые ступени, а по запросу и полный каскад. База `fa9bfc1`. Патч и стенд не требуют студийных файлов для проверки на синтетике.

## Что показала диагностика

- **Ребристый корпус, ступень 3.** После Sewing свободных рёбер 0, оболочка замкнута. После замены лоскутов оболочка открылась. Появилось 104 ребра с допуском выше 0,05 мм, максимум 0,235 мм. Штатный откат сохранил валидный сплайновый результат на 9 000 граней. Обычная раскладка дала 3 433 грани. Опытная ступень дала 4 494 грани, поэтому при сравнении со ступенью без разметки она превышает лимит по граням.
- **Ребристый корпус, ступень 1.** p95 от очищенной сетки к телу 0,0244 мм без разметки, 0,0190 мм при одной смене раскладки и 0,0534 мм при размеченной проекции без замены на точные грани. Штатный режим с разметкой вернул тот же сплайновый результат после отката замены. Здесь рост ошибки появляется уже в проекции.
- **Скруглённая ступень.** У штатной замены 235 рёбер с допуском выше 0,05 мм, максимум 0,2565 мм. Эти рёбра появляются и в исходной оболочке. Повторный трассировочный прогон показал, что девять отклонённых групп увеличили допуски на своих исходных рёбрах. Пробная замена на копии выявила 285 таких рёбер, на исходной оболочке осталось 0. Полный каскад выбрал штатную модель на 604 грани вместо 723 граней с разметкой. Времена для этого прогона 23, 43 и 65 с для трёх режимов соответственно.
- **Публичный тестовый кронштейн, ступень 1.** Разметка потеряла 23 из 12 000 ранее покрытых проб и восстановила 34 других. Из 23 потерь 21 находится вблизи острых рёбер, 7 — вблизи границ разметки, совпадения допускаются. Признак близкой противоположно ориентированной поверхности не сработал. При замене размеченных сплайнов точными гранями ни одна проба не пересекла порог 0,3 мм. Общая доля покрытия выросла с 99,67% до 99,76%, при этом p95 ухудшился с 0,0436 до 0,0664 мм.

Студийный кронштейн в этих прогонах не участвовал. Открытие оболочки и падение покрытия на его конкретных лоскутах ещё нужно подтвердить по локальному отчёту.

Из наблюдения на синтетике следует конкретная проверяемая гипотеза для студийной ступени 3. Сначала нужно сравнить границы сразу после Sewing, затем оболочку до замены граней, затем оболочку после ShapeFix и замены. Если разрыв появляется только после замены, искать группу и соседние лоскуты по координатам и меткам рёбер. Если оболочка открыта сразу после Sewing, причина уже в грубой раскладке или в проекции, и отключение аналитических граней её не устранит. [Open CASCADE Sewing](https://dev.opencascade.org/doc/refman/html/class_b_rep_builder_a_p_i___sewing.html) [Open CASCADE BRepCheck](https://dev.opencascade.org/doc/refman/html/class_b_rep_check___analyzer.html)

## Правило выбора

1. При одинаковом бюджете разметка допускается к раскладке, если p95 грубой сетки не хуже обычного огрубления. При отказе берётся обычная раскладка.
2. Разметка предлагает аналитические опоры без принудительного смещения точек B-сплайнов. Для каждой новой точной грани локально проверяются общие пробы исходных лоскутов и расстояния новой грани до очищенного скана. Замена работает на отдельной копии оболочки. После сборки и исправления проверяются закрытость и допуски всех рёбер кандидата.
3. Сначала строится штатный каскад без разметки. Размеченный результат может его заменить на той же или более ранней ступени, если граней не больше, а измеренные покрытие и p95 сохраняются или улучшаются. Проверяется очищенная поверхность в направлении к телу и сырой скан в обе стороны. Пробы скана фиксированы, обратное направление семплируется отдельно на каждой модели. Если сравнение не подтверждено, сохраняется штатный результат. Когда штатное тело отсутствует, JSON явно отмечает отсутствие базы.

Сравнение измеряет выборку поверхности. Строгие ограничения могут отклонить улучшение p95, если оно требует дополнительных граней. Пробный режим добавляет прогон без разметки, поэтому время нужно замерять на студийных сканах. Флаг по умолчанию выключен.

## Как проверить на сканах студии

В отдельном checkout применить патч из корня репозитория. `$artifact` — путь к этой папке, `$runs` — локальный каталог результатов, `$alignedScan` — выровненный STL из прогона демо, `$sheet` — соответствующий лист замеров. Для исходного скана без листа можно указать `--tol`. Для синтетики с равномерной сеткой нужен `gmsh==4.15.2` только в окружении стенда.

```powershell
git apply --check "$artifact/regions_guard.patch"
git apply "$artifact/regions_guard.patch"
$env:PYTHONUTF8 = '1'
$env:OPENBLAS_NUM_THREADS = '1'
python "$artifact/benchmark_region_guard.py" --demo claude/cad-demo --work $runs --scan $alignedScan --sheet $sheet --steps 1 3
```

Для финальной проверки добавить `--cascade`. Для одной диагностики сшивки можно запустить `--steps 3 --modes stock --trace-only`. Стенд сохраняет STEP и JSON в `$runs`. В JSON есть свободные рёбра после Sewing, завышенные допуски до и после замены, статусы OCCT и координаты проб, которые вышли из допуска. Близость к границе разметки, острому ребру и противоположно ориентированной поверхности показана отдельно. Последний признак указывает возможную тонкую стенку.

Режимы `off`, `stock`, `layout_only`, `projected_splines` и `guarded` используют один подготовленный скан. `layout_only` меняет раскладку, сохраняя прежнюю обработку плоскостей. `projected_splines` сохраняет размеченную проекцию и пропускает замену сшитых лоскутов. Сравнение этого режима со `stock` проверяет вклад замены после сшивки. Сегментация кэшируется в диагностической матрице, её время записано отдельно.

На равномерной синтетике с шумом σ 0,05 мм проверены ребристый корпус, скруглённая ступень и криволинейная крышка. Отдельно проверен публичный скан кронштейна. Сопоставление с эталоном использует стенд задачи 12. Все результирующие опытные STEP в матрице валидны и замкнуты. У тестового кронштейна p95 по сырому скану достиг верхней границы поиска 1,2 мм, поэтому это значение отмечает насыщение шкалы. [Результаты и координаты](results.json).

Проверены равные и ухудшенные точные грани, отказ при превышении числа граней, четыре свободных ребра на открытой оболочке и завышенный допуск ребра с двумя соседями. `selftest.py` прошёл на Python 3.12. Python 3.10 и 3.11 в окружении отсутствовали. Платный ИИ не использовался.
