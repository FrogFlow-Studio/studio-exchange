# Запуск с ИИ самому (Windows)

Один раз: Python 3.11 или 3.12 с python.org (галочка «Add to PATH»), потом двойной щелчок
по `install.bat`.

Каждый запуск:

1. Открыть папку `claude\cad-demo`, в адресной строке проводника набрать `cmd`, Enter.
2. Вставить ключ (только в это окно, никуда не сохраняется):
   ```
   set ANTHROPIC_API_KEY=ваш_ключ
   ```
3. Запустить на своём скане (путь и заметку поменять):
   ```
   python demo.py C:\сканы\деталь.stl --notes "что сломано" --budget-usd 0.8
   ```
   Без своего скана можно взять тестовую: `samples\flange_scan.stl`.

Что увидите: попытка 0 (алгоритм без ИИ), потом попытки ИИ. У каждой строки «ИИ сделал
запросов к сетке» и «расход пока: $…». Прогон сам остановится, если расход выше
`--budget-usd`. В конце откроется отчёт `out\<время>\report.html`, рядом `model.step` и
`model.stl`.

Если скан не в миллиметрах, добавить `--units cm` (или `m`, `in`).
Если деталь целая и ничего достраивать не надо, написать в заметке «деталь целая».
