# Задача 20а. Оценка шума на крупной сетке

`coarse_noise.estimate(mesh)` принимает выровненную сетку в миллиметрах. Возвращает `noise_mm`, метод, число принятых окрестностей и диагностику опорной плоскости. Для прямого импорта положите папки задачи 20а и задачи 18 в `PYTHONPATH`. Модуль использует NumPy, SciPy и прежнюю подгонку квадратики из `scan_noise.py`.

На крупной сетке 32 ближайшие связанные вершины могут лежать по обе стороны сгиба. В новом методе связность идёт по граням. Переходы через большой двугранный угол и грани с сильно отличающейся нормалью отсекаются. Квадратика строится по 12 вершинам. Для устойчивости берётся 30-й процентиль локальных остатков, по возможности на подмножестве с низкой кривизной. Поправка на шесть степеней свободы откалибрована для независимого гауссовского шума с фиксированными координатами в регрессии. На реальном скане это приближение, поэтому результат проверен синтетикой с шумом по всем трём координатам. [Остатки нормальной регрессии](https://www.stat.rice.edu/~dobelman/courses/texts/qualify/Math.Stat.Geyer.5101-5102.pdf) · [Функция SciPy для поправки](https://docs.scipy.org/doc/scipy/reference/generated/scipy.special.gammaincinv.html)

## Опорная плоскость и p95

- У студийного кронштейна в отчёте площадь кандидатов 0,4%. В задаче 18 порог 2,5% прекращал проверку сразу. Теперь размер опоры подтверждают достаточное число плоских окрестностей и двумерный разброс точек. Контрольная синтетическая площадка площадью 0,19% вернула прежнюю оценку по центрам граней 0,027 мм.
- У линзы доля 7% проходит старый порог площади. По имеющимся числам нельзя выбрать между глобальной проверкой кривизны, недостатком подходящих локальных участков и расхождением высотного разброса с локальной оценкой. Стенд пишет `task18_support_status` и `task20a.support_status` при прогоне исходной сетки. Новый метод отдельно проверяет, объясняется ли разброс высот наклоном опоры. При подтверждённой плоскости штатная шкала центров граней сохраняется, `vertex_sigma_mm` хранится отдельно.
- `--clean-p95` меряет расстояния от выборки сырых вершин до очищенной поверхности. Эта поверхность вычисляется из того же скана. Сглаживание может сохранять часть ошибок и менять форму вблизи рёбер. Поэтому p95 записывается для диагностики, а ограничение оценки сверху по нему не применяется.

```powershell

$env:OPENBLAS_NUM_THREADS = "1"
python "$task/benchmark_coarse_noise.py" --demo claude/cad-demo --work "D:/local/task20a" --controls
python "$task/benchmark_coarse_noise.py" --demo claude/cad-demo --work "D:/local/task20a" --reuse --seed 200212 --output "D:/local/task20a/holdout.json"
python "$task/benchmark_coarse_noise.py" --demo claude/cad-demo --work "D:/local/task20a-studio" --skip-synthetic --aligned --clean-p95 --scan lens "D:/local/lens/scan_aligned.stl" --scan bracket "D:/local/bracket/scan_aligned.stl" --scan hyundai "D:/local/hyundai/scan_aligned.stl"
```

Для исходного файла без штатного выравнивания уберите `--aligned`. Студийный прогон остаётся у Компаса. Порогов 0к этот стенд не меняет.
